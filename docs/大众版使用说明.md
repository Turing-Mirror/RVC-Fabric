# Turing Mirror 变声器 · 使用说明

本文与软件内导航 **「说明」** 页内容一致，按本软件实际按钮与页面编写。  
设置页每一项旁也有注释（文字 + 悬停「?」），可对照使用。

---

## 1. 这是什么软件

本地**实时变声**：麦克风 → 换成所选音色 → 经虚拟声卡进游戏 / QQ / Discord。

日常路径：**启动器（首次）→ 变声器主界面 → 选音色 → 设设备 → 开启变声**。  
训练 / 翻唱在「其他 → WebUI」，不是每次开黑都要开。

---

## 2. 第一次怎么开

1. 解压到尽量**英文路径**  
2. 打开 **启动器**  
3. **发送快捷方式**  
4. **安装虚拟声卡**（VB-Cable）  
5. **检测与部署**（日常必需；训练资源可选）  
6. **打开变声器**

首次检测时短暂黑框多为 Runtime 加载，一般会自行关闭。

---

## 3. 声卡接线（最重要）

| 位置 | 选什么 |
|------|--------|
| 本软件 **输入设备** | 真实麦克风 |
| 本软件 **输出设备** | **CABLE Input** |
| 本软件 **监听设备**（可选） | 耳机 / 音箱 |
| 游戏 / QQ 麦克风 | **CABLE Output** |
| Windows 默认播放 | 耳机（不要 CABLE） |

装完声卡后若列表没有设备：设置里「重载设备列表」，或重启软件。

---

## 4. 日常开黑

1. **首页 / 模型** 选音色  
2. **设置** 确认设备；需要听自己则勾选「变声时监听自己」  
3. 底栏 **开启变声**（首次 20～40 秒）  
4. 游戏麦 = CABLE Output  
5. 结束时再点停止，或「其他 → 强制结束变声引擎」

底栏 **输出变声 / 原声旁路**：前者正常变声，后者只测麦与接线。  
音高 / 共鸣 / 阈值可在底栏调节，并按音色保存。

## 6. 音色

- **模型 → 导入模型**，或 **更新** 页在线下载  
- `.pth` 为推理模型；`.index` 可选（特征检索，不是训练底模）  
- 每个音色可单独记住音高、共鸣等  

---

## 7. 设置项效果摘要

详见设置页每项下方注释。简要：

| 名称 | 改了会怎样 |
|------|------------|
| 加速后端 | 换 CUDA / DirectML / CPU；按发行包来，勿混 Runtime |
| 输入 / 输出 / 监听 | 决定麦从哪进、变声往哪出、自己听哪路 |
| 响应阈值 | 多小声才变声；环境吵可调高 |
| 音高 Pitch | 半音高低；男→女常 +8～+12 |
| 共鸣 Formant | 音色明暗 / 腔体感 |
| Index Rate | 有 .index 时更「像」训练音色；无 index 当 0 |
| 响度因子 | 输出是否跟随你原来的音量起伏 |
| 音高算法 | fcpe / rmvpe 等；卡顿可换轻量算法 |
| 采样长度等 | 稳与延迟的平衡；改后需重新开启变声 |
| 降噪 / 效果链 | 更干净或更「稳」，更吃性能；效果链默认关 |

## 8. 常见问题

**对面没变声** → 游戏麦是否 CABLE Output；本软件输出是否 CABLE Input；是否已开启且为「输出变声」。  

**自己听不到** → 勾选监听自己，监听选真实耳机。  

**卡顿延迟大** → 略增采样长度；关一项降噪；确认显卡对应发行包。  

**音高不对** → 调 Pitch；有 index 时试 Index Rate 0.3～0.75。  

**停不干净** → 其他 → 强制结束变声引擎。  

**完整大更新** → 更新页 SharePoint / QQ 全量包，解压到新目录。
