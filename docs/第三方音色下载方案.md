# 模型广场(社区下载改版)与第三方音色源 · 实施方案

> **状态**:已实施（1.2.2）。入口文案定为 **「社区音色」**（即原方案「模型广场」）。
> **拟定日期**:2026-07-27；实施 2026-07-29（命名改为社区音色；热度排序本期不做）
> **相关文档**:`docs/在线更新与音色库.md`(现有包规范)、`docs/CNB-index索引与封面.md`(清单编译与封面 SOP)
> **实现代码(现有)**:`launcher/online/`、`launcher/ui/store_page.py`、`scripts/build_catalog.py`

## 1. 背景与产品决策

现状:社区下载只有 RVC Fabric 制作组维护的 CNB 官方源(`index.json` → `voices[]`)。

目标:下载页升级为**「模型广场」**,同时提供两类源——**图灵镜源**(自维护官方源)与
**第三方源**(Hugging Face / voice-models.com 等社区),并为二次元/游戏角色自动匹配
官方立绘作封面。

已定决策(2026-07-27):

| 决策项 | 结论 |
|---|---|
| 页面命名 | 「社区下载」全面更名 **「社区音色」**(入口按钮、对话框标题、帮助文案；与导航「广场」资讯页区分) |
| 源命名 | **图灵镜源**(官方 CNB)/ **第三方源**(HF 等);界面与数据层都显式区分 |
| 内容范围 | 二次元/游戏角色 + 真人声音均开放 |
| 授权政策 | **图灵镜源:收录须取得模型作者授权**(运营义务,YAML 记录);**第三方源:不需要我们取得授权** — 仅索引与外链,授权/版权归属由来源站点与上传者负责 |
| 默认展示 | **最新在前**(按发布/收录日期 YYMMDD);我们没有后端数据库,做不了全局"最热" |
| 热度排序 | 可选增强(P1):第三方条目用 **HF 下载量快照**(收编/刷新时抓取)做"热门"排序;图灵镜源无数据来源,不做 |
| 封面策略 | 二次元角色:Bangumi 自动匹配 + **人工过目**;真人:留空(后续人工/AI 生成补图,零代码改动) |
| 架构 | **运营侧管线 + 客户端消费**:客户端不做任何爬取与 AI,只消费审核过的清单 |
| voice-models.com | 无公开 API,仅作运营侧"选品货架";溯源到背后的 HF 仓库后用工具收编,客户端**永不直连** |
| Hugging Face | 第三方源数据主体;国内默认走 hf-mirror.com 镜像 |
| 官方身份隔离 | 第三方安装**不得**带 `fabric_official` / `publisher: rvc_fabric` 官方章 |

## 2. 双源政策(运营口径)

| | 图灵镜源 | 第三方源 |
|---|---|---|
| 内容来源 | 制作组自制 / 社区作者投稿 | HF 等站点公开模型,运营选品收编 |
| 授权 | **须取得作者授权后收录**;授权出处记录进 YAML(见 §5.1) | 不由我们取得授权;来源站点已公开分发,我们仅索引直链 |
| 制品托管 | CNB 仓(zip + LFS),我们控制 | 原站(HF),我们不镜像不二传 |
| 质量责任 | 制作组审核(试听、调参、封面) | 免责声明 + 逐条溯源链接,用户自行判断 |
| 封面 | ch-banner 官方维护 | Bangumi 匹配 + 人工过目;真人留空 |
| 身份章 | `publisher: rvc_fabric` + `fabric_official: true` | `publisher: community` + `fabric_official: false` |
| 下架 | 删 YAML + 删制品 → build → push | 删 YAML → build → push(原站内容不受影响) |

图灵镜源授权记录:默认写在官方 `catalog-src/voices/<id>.yaml` 的**注释**里
(注释不会编译进公开的 index.json,授权凭证不外泄):

```yaml
# 授权:望月星逸 260723 同意收录,B 站私信存档见 <内部链接>
id: Tomori
```

仅当作者同意**公开**授权声明时,才写成 `authorization:` 字段(未知键会透传进公开索引)。
存量音色补录注释即可;详见 `docs/音色仓库维护手册.md` §5.3。

## 3. 总体架构与数据流

```
[运营侧·维护机]                              [CNB 制品仓]              [客户端·模型广场]
add_thirdparty_voice.py --hf user/repo        index.json 新增顶层键     ┌ 最新(默认): 双源合流,最新在前
  ├─ hf-mirror API: 文件清单 + sha256    →    thirdparty_voices[]  →   ├ 图灵镜源: 官方列表(现首页)
  ├─ 同时抓 downloads/likes 快照(热度)        (老客户端读不认识的      ├ 第三方: 免责声明 + 溯源 + 可选热度排序
  ├─ 启发式提取角色名(--name 可覆盖)           键自动忽略,零风险)      └ 系列专区: 官方系列折叠(现状)
  ├─ Bangumi 搜角色 → 封面落 ch-banner/                                下载: huggingface.co → hf_endpoint 镜像重写
  └─ 生成 catalog-src/thirdparty/<id>.yaml                             安装: voice_files/voice_pack 通道复用,不盖官方章
        ↓ 人工过目(封面/名字/选品)
build_catalog.py build --diff(现有 SOP 不变)
```

要点:

- AI / 启发式 / 网络爬取全部收在运营侧脚本;客户端只多解析一个清单键、多两个视图、
  多一条 URL 重写规则。**广场无后端、无遥测**:所有"热度"都是 build 时写死的快照。
- 三份产物(`index.json` / snippet / `configs/online_catalog.json`)同步携带
  `thirdparty_voices`,沿用「生成物勿手改」纪律。
- 清单里 URL 统一存 `huggingface.co` 规范形态;镜像重写是**客户端行为**(镜像可换、可退)。

## 4. 外部依赖调研结论(2026-07-27)

| 依赖 | 结论 |
|---|---|
| HF 模型 API | 免费匿名。`GET {ep}/api/models/<org>/<repo>` 仓库信息(**含 downloads / likes,可作热度快照**);`GET {ep}/api/models/<org>/<repo>/tree/main?recursive=true` 文件树,**LFS 文件带 `lfs.oid`(即 sha256)与 size** — 第三方也能做哈希校验 |
| HF 直链 | `{ep}/<org>/<repo>/resolve/main/<path>`,302 到 CDN,支持 Range(multipart 可用) |
| hf-mirror.com | 公益镜像,实时同步 API/resolve/LFS,2026-07 仍正常运营;国内直连可达 |
| voice-models.com | 27,900+ 模型目录站,**无公开 API**;下载指向 HF / Google Drive(国内不可达)等 |
| Bangumi API | `api.bgm.tv`,免费,须带自定义 User-Agent;角色搜索(v0 `POST /v0/search/characters`,body `{"keyword": …}`)返回含 `images`(角色官方图)。**端点与字段以实施时实测为准**(见 §12 前置验证) |

## 5. 清单 schema

### 5.1 运营源:`CNB-GIT-RELEASE/catalog-src/thirdparty/<id>.yaml`

一色一文件,由 `add_thirdparty_voice.py` 生成、人工修订。字段:

```yaml
id: tp-miku            # 必填;强制 tp- 前缀(见下)
name: 初音未来          # 展示名(工具启发式猜测,人工确认)
tag: 二次元            # 真人条目写: 真人
series: VOCALOID       # 可选;仅参与搜索,不参与系列专区分组
origin: huggingface    # 来源标识(预留 voice_models 等)
source_url: https://huggingface.co/TheUser/MikuRVC   # 溯源页,行内可点
author: TheUser        # HF 上传者(非角色声优)
author_url: https://huggingface.co/TheUser
package_type: voice_files            # 或 voice_pack(HF 上只有 zip 时)
pth_url: https://huggingface.co/TheUser/MikuRVC/resolve/main/miku.pth
index_url: https://huggingface.co/TheUser/MikuRVC/resolve/main/miku.index  # 可选
# pack_url: https://huggingface.co/.../resolve/main/miku.zip   # voice_pack 时用
sha256: <64 位 hex>    # 取自 HF tree API 的 lfs.oid;非 LFS 文件允许留空(build 警告)
size_bytes: 55180000
real_person: false     # 真人 = true;true 时工具跳过 Bangumi
date: '260727'         # 收录日期 YYMMDD(参与"最新"排序)
cover: ch-banner/tp-miku.jpg   # 可选;Bangumi 匹配成功且人工确认后才有
description: 收录自 Hugging Face;非官方音色
hf_downloads: 15320    # 可选;收编时 API 快照,热度排序用(P1)
hf_likes: 87           # 可选;同上
snapshot_date: '260727'  # 可选;快照抓取日期
```

规则:

- **`id` 强制 `tp-` 前缀**:安装目录为 `User_Data/models/<id>/`,前缀避免与官方 id
  (`kiki` / `Tomori` …)撞目录;build 校验强制。
- id 在官方 `voices/` 与 `thirdparty/` **两个命名空间内全局唯一**,重复报错。
- YAML 内出现 `fabric_official: true` 或 `publisher: rvc_fabric` → **build 直接报错**(防手滑)。
- 封面小图走 git/raw(与官方 ch-banner 同规则,勿 LFS)。

## 6. 客户端改动明细

### 6.1 `launcher/online/catalog.py`

- `VoiceEntry` 新增字段:
  - `origin: str = ""`(`huggingface` / 预留其它;空 = 图灵镜源)
  - `source_url: str = ""`

## 7. 运营侧改动明细

### 7.1 `scripts/build_catalog.py`

- `load_sources`:读 `catalog-src/thirdparty/*.yaml` → `out["thirdparty"]`;
  **目录不存在 = 空列表,不报错**(老仓库/最小 fixture 兼容)。
- 新增 `_compile_thirdparty_voice(v, paths, rep)`:
  - 校验:id 必填 + `tp-` 前缀 + 跨官方/第三方全局唯一;`pth_url` 或 `pack_url`
    至少其一且为 http(s);`date` 规范 YYMMDD;`origin` 缺省补 `huggingface`;
  - `sha256` 缺失 → **警告**(允许,非 LFS 文件没有现成哈希);格式错(非 64 hex)→ 错误;
  - `fabric_official: true` / `publisher: rvc_fabric` → **错误**;
  - `cover` 为相对路径时检查 `paths.cnb / cover` 存在,否则警告(与官方同);
    `cover_url` 由 `cnb_raw_url` 推导;
  - `hf_downloads` / `hf_likes` / `snapshot_date` 原样透传(P1 排序数据);
  - 产物条目固定携带 `"official": false`、`"publisher": "community"`(或 YAML 显式
    的非 rvc_fabric 值)。
- `compile_catalog`:`thirdparty_voices` 数组进 index / snippet / bundled 三份产物;
  排序与官方一致(date + id)。
- 官方 voices 的授权记录:默认 YAML 注释(不进产物,见 §2);`check` 增加一条**警告**:
  官方音色 YAML 原文里既无 `# 授权` 注释也无 `authorization:` 字段时提示补录
  (读原文匹配,不阻断,存量待补)。
- `_roundtrip_check`:三份产物喂 `OnlineCatalog.from_dict`,
  `len(cat.thirdparty_voices)` 必须等于源条数(与现有 voices 回环同款);
  官方 voices 数量校验保持不变(第三方绝不混入 `voices[]`)。
- `_semantic_diff` 天然支持新键,`build --diff` 无需改动。

### 7.2 `scripts/add_thirdparty_voice.py`(新,纯 stdlib)

```bat
python scripts\add_thirdparty_voice.py --hf TheUser/MikuRVC ^
    [--id tp-miku] [--name 初音未来] [--series VOCALOID] [--tag 二次元] ^
    [--real-person] [--bangumi-id 10452] [--no-cover] ^
    [--endpoint https://hf-mirror.com] [--cnb <CNB-GIT-RELEASE 路径>]
```

流程:

1. `GET {ep}/api/models/<repo>`(取 downloads/likes 快照)+
   `/tree/main?recursive=true`(urllib,UA 带产品名);
2. 选制品:优先最大的 `.pth`(> 50 KB)+ 同干名 `.index` → `voice_files`;
   仓库只有 zip → `voice_pack`(`pack_url`);多候选打印列表人工 `--pth-path` 指定;
3. sha256 / size 取 `lfs.oid` / `lfs.size`;非 LFS 文件留空并提示;
4. 角色名:`--id` 缺省由仓库名 slug 化(`tp-` + 小写安全化);`--name` 缺省用启发式:
   - 去扩展名,`[_\-.]` → 空格;
   - 剥离 token(不区分大小写):`RVC`、`v1/v2`、`e?\d+ ?epochs?`、`s?\d+ ?steps?`、
     `\d+k`、`harvest/crepe/rmvpe/fcpe`、`model/voice/AI/TTS`、括号及其内容;
   - 剩余首个词组为猜测名,打印出来**要求人工确认**(直接回车接受或输入修正);
5. 封面(`--real-person` / `--no-cover` 时跳过):
   - Bangumi 角色搜索(keyword = 确认后的名字),打印前 5 候选(id / 名 / 图 URL);
   - 下载首选(或 `--bangumi-id` 指定项)大图到
     `CNB-GIT-RELEASE/ch-banner/<id>.jpg`;
   - 打印提示:**人工看图**;不满意 → `--bangumi-id` 重跑或删图(YAML 去掉 cover 行);
6. 写 `catalog-src/thirdparty/<id>.yaml`(带"人工维护"文件头,同官方 voices 风格,
   含 `hf_downloads` / `hf_likes` / `snapshot_date`);
7. 打印后续:`python scripts\build_catalog.py build --diff` → 核对 → CNB 仓提交推送。

设计约束:

- 只依赖 stdlib(urllib/json/argparse/re);YAML 写出用 `yaml.safe_dump`(维护机已装 PyYAML);
- 所有网络请求 15s 超时 + 明确错误文案;Bangumi 请求必带自定义 User-Agent
  (如 `Turing-Mirror/RVC-Fabric (https://github.com/Turing-Mirror/RVC-Fabric)`);
- 工具本身**不下载 .pth**(几十 MB 起),哈希全取 API 元数据 — 收编一个音色的
  网络开销 = 两个 JSON + 一张封面图。

### 7.3 快照刷新(P2,可选)

`add_thirdparty_voice.py refresh`:遍历 `catalog-src/thirdparty/*.yaml`,重抓各仓库
downloads/likes 更新快照字段。不做定时任务;发版前顺手跑一次即可。

## 9. 安全与合规边界

| 层 | 机制 | 状态 |
|---|---|---|
| 下载 | sha256 校验(HF LFS oid) | 复用现有 `download_file(expected_sha256=…)`;缺哈希时跳过校验(音色本就允许) |
| 解压 | `safe_zip` 防 zip-slip | 现有,零改动 |
| 包类型 | `detect_zip_package_type` 嗅探,full_package 拒装 | 现有,零改动 |
| 模型加载 | `.pth` 不可信 pickle → `infer/lib/safe_load.py`(weights_only + 路径圈定) | 现有引擎侧机制,零改动;第三方模型天然过这道闸 |
| 身份 | 第三方永不带官方章;包内伪装章被强制压掉 | 本方案 §6.3,新增测试钉死 |
| 授权 | 图灵镜源:作者授权 + YAML 记录(§2);第三方源:仅索引,不背书 | 运营纪律 + build 警告提示补录 |
| 内容 | 运营选品 + 人工过目 = 人工闸门;免责声明 + 逐条溯源链接 | 本方案 §7.2 / §8 |
| 下架 | 删 YAML → build → push,客户端刷新即消失(双源同机制) | 沿用现有清单机制 |

版权口径:角色立绘为版权物;经 Bangumi 匹配后复制入 CNB 仓分发,与现有官方音色封面
(MyGO 立绘)处于同一风险水位,不新增风险类别;真人条目无封面。
