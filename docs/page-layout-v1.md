# 页面布局与切换 v1

日期：2026-11-07。

说明页与其他页使用与 GPT-SoVITS Fabric 相同的居中阅读宽度，复用 TRM UI PagePad 的 read 模式。说明页顶层小节间距统一为 24px。设置页保留原有全宽布局和八个类别的横向可达性。

设置类别、模型 RVC/DSP 类别与分页、高级参数类别、音频变声/文字合成类别和存储实验分页复用 CatalogTransition。内容按类别顺序或页码整块左右平移，不淡出、不缩放；输入、任务状态和进度更新保留当前内容。模型翻页不再叠加逐卡浮现。

工具窗固定底栏只渲染活动内容的操作，避免离场内容保留期间出现两套操作按钮。

其他页的移动端监听与输出控件限制宽度并允许换行。增益滑块提供明确宽度，窄行可换行；不改变设备选择、开关或增益设置行为。
