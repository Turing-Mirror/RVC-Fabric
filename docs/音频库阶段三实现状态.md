# 音频库阶段三实现状态

更新于 2026-09-23，分支 `tm-release`。本阶段延续[阶段一](音频库阶段一实现状态.md)和[阶段二](音频库阶段二实现状态.md)。

## 已实现

- 音频库和旧裁剪入口共用波形选区组件。长音频由后台 FFmpeg 流式提取峰值并缓存到 `User_Data/audio/cache/peaks/`；WebView 不再读取整首音频来计算波形，画布只覆盖可见区域。
- 切换文件会取消旧的后台波形任务，旧结果不会覆盖新文件。峰值提取失败时仍可用时间输入与既有裁剪操作。
- 音频库可在波形上选择草稿范围。“试听选区”使用草稿，不需先保存；“应用播放范围”和“另存为 WAV”仍是独立操作。
- 保存片段范围时以后端探测到的真实时长校验，避免把超出源文件的范围写入音频库。

## 尚未完成

- 语音内播放与混音、叠加播放、动态快捷键和悬浮窗播放控制尚未接入。
- 旧裁剪入口的播放仍沿用其原有 HTML 音频试听方式；本阶段仅替换波形提取与绘制，未声称它具备音频库的本地设备隔离。
- Windows 声卡、CABLE 隔离和安装包实测待用户回到 Windows 后进行。
