# 音频与快捷键阶段十四实现状态

更新于 2026-09-24，分支 `tm-release`。本阶段接续[阶段十三](音频与快捷键阶段十三实现状态.md)。

## 已实现

- 音频页的活动实例增加“重播”，从该条目已保存的片段起点重新播放。快捷键新增“重播当前音频”，默认不绑定，作用于最近触发的实例。
- 重播只替换目标实例所在的混音槽，不停止其他叠加实例；新音频解码准备失败时原实例继续播放。
- 准备期间若目标已停止、设备失效，或较新的播放／停止请求取代本次请求，迟到的解码结果会被拒绝，不会重新出声。
- 八语言文案同步；页面沿用已有播放按钮样式。

## 验证

- 混音槽选择与目标消失后的拒绝逻辑通过 Rust 定向测试；音频页实例级按钮测试通过。
- TypeScript、相关组件 ESLint、八语言检查和 Windows 目标静态编译通过。当前环境未做真实声卡的点击声、延迟和重播听感测试。

## 仍待完成

- 循环与片段内拖动进度尚未接入。重播目前要求目标实例仍在活动列表中；播放结束后不会把“最近一首”自动重新启动。
- 旧九项系统占用组合键时的回滚、设置页进一步分组与筛选，以及 Windows 实机验收仍未完成。
