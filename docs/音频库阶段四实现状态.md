# 音频库阶段四实现状态

更新于 2026-09-23，分支 `tm-release`。本阶段延续[阶段三](音频库阶段三实现状态.md)。

## 已实现

- 音频库条目可按已保存的播放范围输出到用户明确选择的设备，不依赖 Python Runtime、模型或变声引擎。输出设备选择单独保存，不随系统默认设备变化。
- 本地试听与语音输出共用原生播放会话的解码、状态、暂停、结束和取消逻辑，但各自拥有独立会话。本地试听仍禁止选择已配置的语音输出设备。
- 语音输出与旧 RVC／DSP 输出互斥：播放或准备播放期间拒绝启动变声；变声正在启动或运行时拒绝开始语音输出。不会在当前过渡阶段让两条输出流同时写入目标设备。
- 音频页提供语音输出设备选择、播放、暂停、继续、停止和进度；八种语言同步。切换页面或隐藏窗口不会停止后台播放，退出应用会停止。

## 尚未完成

- 变声与音频同时输出、统一目标输出所有权、无缝切换、叠加、循环、定位和全局快捷键尚未实现；当前界面明确标注语音输出仅在变声停止时可用。
- Windows 声卡、虚拟声卡与安装包实测待用户回到 Windows 后进行。本阶段不声称已验证实际 CABLE 收音效果。
