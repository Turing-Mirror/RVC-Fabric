# 广场下载与动效 v1

日期：2026-11-07。

## 下载

RVCF 移除未安装引擎时隐藏模型列表及阻止附加模型下载的限制。下载时仍能浏览和翻页，实际变声与训练继续检查自身依赖。删除八种语言中的固定“约 720 MB”和前置下载提示，下载大小来自 `assets_status.engine_core_size_bytes`，由已有下载清单解析；未知大小不显示。简化基础资源用途说明，不在下载卡片堆叠缺失文件路径。

匿名回读公开 CNB 清单，确认 RVCF 的附加资源只有人声分离和训练两类，无含糊的“其他”条目。本次不修改发布清单或上传任何资源及公告。

## 动效

RVCF 与 GSVF 广场下载分类、模型分页、社区来源与分类、社区分页及更新日志分页接入 TRM UI 的 `QueueList` 和 `Morph`。产品的 `CatalogTransition` 只组合组件，不复制动效实现。内容整层水平推移，上一页与下一页方向相反；高度变化平滑过渡。公共标题、基础资源卡和分页控制保留原位置。分类说明使用 `Roll`。

下载进度不属于分类或分页身份，因此更新进度时不切换内容。快速操作采用组件的最新目标处理，退出内容不可交互，减少动态效果时立即切换。原有布局、颜色与下载任务持久化方式保持不变。

## 验证

- RVCF 前端 261 项、GSVF 前端 62 项测试通过；两边类型检查、lint、八语言文案检查与前端构建通过。
- RVCF 原生资源模块 8 项测试通过，包括清单大小到状态接口的验证。
- Chromium 使用真实组件及清单、模拟原生接口，验证两边未安装引擎时能直接下载，没有触发基础资源安装。
- 两边分类正向、反向、模型分页、社区分页各采集 32–33 帧：新旧层不重叠、全程不透明、无缩放，退场层不可交互；结束后不残留旧层。
- 快速连续切换正确落在最后请求的分类；下载进度更新不重播过渡；减少动态效果时立即切换。
- 八语言 880×640 检查无横向溢出，浏览器异常为零。

浏览器验证使用临时脚本，不上传示例角色，不进行真实模型下载或训练。真实桌面窗口的主观动效验收不由模拟接口检查替代。
