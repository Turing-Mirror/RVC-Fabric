# RVC Fabric · 使用说明

本文与软件内导航 **「说明」** 页内容一致，按本软件实际按钮与页面编写。  
设置页每一项旁也有注释（文字 + 悬停「?」），可对照使用。

---

## 1. 这是什么软件

**RVC Fabric** 是本地**实时变声**工具：麦克风 → 换成所选音色 → 经虚拟声卡进游戏 / QQ / Discord。

日常路径：**启动器（首次）→ 主界面 → 选音色 → 设设备 → 开启变声**。  
训练 / 翻唱在「其他 → WebUI」，不是每次开黑都要开。

---

## 2. 第一次怎么开

1. 解压到尽量**英文路径**  
2. 打开 **启动器**  
3. **发送快捷方式**  
4. **安装虚拟声卡**（VB-Cable）  
5. **检测与部署**（日常必需；训练资源可选）  
6. **打开主界面**

请用桌面快捷方式、启动器或发行包入口启动；不要用会弹黑框的方式直接跑控制台 Python（调试除外）。

---

## 3. 声卡接线（最重要）

| 位置 | 选什么 |
|------|--------|
| 本软件 **输入设备** | 真实麦克风 |
| 本软件 **输出设备** | **CABLE Input** |
| 本软件 **监听设备**（可选） | 耳机 / 音箱 |
| 游戏 / QQ 麦克风 | **CABLE Output** |
| Windows 默认播放 | 耳机（不要 CABLE） |

装完声卡后若列表没有设备：设置里「重载设备列表」，或重启软件。

---

## 4. 日常开黑

1. **首页 / 模型** 选音色  
2. **设置** 确认设备；需要听自己则勾选「变声时监听自己」  
3. 底栏 **开启变声**（首次 20～40 秒）  
4. 游戏麦 = CABLE Output  
5. 结束时再点停止，或「其他 → 强制结束变声引擎」

底栏 **输出变声 / 原声旁路**：前者正常变声，后者只测麦与接线。  
音高 / 共鸣 / 阈值可在底栏调节，并按音色保存。  
可在「模型」页使用**配置档案**（`.tmvp`）保存/导入整套参数。

### 发给团队的咨询包（调参服务）

需要团队帮你调参时：

1. 选中要用的用户音色  
2. **其他 → 生成咨询包**，或模型页配置档案区 **打包咨询包…**  
3. 填写角色名，选择**原声**与**变声后效果**两段音频（建议各 10–30 秒）  
4. 官方库音色默认只写入身份信息；自备模型可按需勾选「包含模型文件」  
5. 生成后的 zip 在 `User_Data/consult_packs/`，发给团队即可  

说明：软件参数始终可自行调节；配置档案也可单独导出互享。咨询包只是方便团队对照样本调参，不会自动上传。

## 6. 音色

- **模型 → 导入模型**，或 **更新** 页在线下载  
- `.pth` 为推理模型；`.index` 可选（特征检索，不是训练底模）  
- 每个音色可单独记住音高、共鸣等  

---

## 7. 设置项效果摘要

详见设置页每项下方注释。简要：

- **加速后端**：按发行包（N 卡 cuda / A 卡 dml），勿混 Runtime  
- **音高 / 共鸣 / 阈值**：运行中多半可热更新  
- **延迟预设**：低延迟 / 均衡 / 稳定  
- **声音效果**：门/压缩/EQ，默认关  

---

## 8. 常见问题

**对面听不到？** 游戏麦是否 CABLE Output；软件输出是否 CABLE Input；是否已开启变声。  

**自己听不到？** 勾选监听自己，监听设备选真耳机。  

**卡顿？** 加大采样长度 / 换预设；关降噪；确认显卡分版 Runtime。  

**停不干净？** 「其他 → 强制结束变声引擎」。  

**完整大包更新？** 走 SharePoint / 社群下载全量包到新目录，勿指望进程内覆盖 Runtime。
