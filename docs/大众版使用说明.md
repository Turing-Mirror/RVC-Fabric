# RVC 大众版使用说明（对齐 B 站 RVCMAX 流程）

参考视频：[RVCmax2026（小源AI变声器）](https://www.bilibili.com/video/BV1WVzYBcE2K)

目标体验：**解压 → 双击启动器 → 发快捷方式 / 装虚拟声卡 → 桌面图标打开白净软件界面**，而不是一直对着黑色命令行。

---

## 1. 发布包目录长什么样

对齐热门视频中的文件夹：

| 名称 | 作用 |
|------|------|
| `启动器.vbs` / `启动器.exe` | 首次使用的「源星式」小窗口 |
| `启动软件.vbs` | 直接进主界面（无黑框） |
| `Runtime` 或 `runtime` | 绿色 Python 环境（可选，有则免装 Python） |
| `launcher/` | 启动器 + 主界面代码 |
| `VBCABLE/` | 虚拟声卡安装包放置处 |
| `UserData/` | 你的配置 |
| `assets/weights/` | 音色 `.pth` |
| 其余 `infer*` 等 | RVC 引擎核心（相当于视频里的 RVC_Core） |

---

## 2. 第一次使用（懒人三步）

1. **双击 `一键启动.bat` 或 `启动器.vbs`**  
   弹出粉白卡片窗口（发送快捷方式 / 安装虚拟声卡 / 一键部署）。

2. **点「发送快捷方式」**  
   桌面出现「RVC变声器」图标。之后日常只双击桌面图标，**不会出现黑框**。

3. **点「安装虚拟声卡」**  
   - 若 `VBCABLE` 里已有 Setup：自动打开安装，点 Install。  
   - 若没有：自动打开官网，下载后把 `VBCABLE_Setup_x64.exe` 放进 `VBCABLE` 再点一次。

可选：点「一键部署环境」自动下载 hubert / rmvpe 等预训练文件。

然后点 **「启动变声软件」**，或关闭启动器后用桌面图标。

---

## 3. 主界面怎么用（白净窗口）

| 页签 | 功能 |
|------|------|
| 首页 | 左右切换音色，底部「开启变声」 |
| 模型 | 网格查看 / 导入 `.pth` / 打开文件夹 |
| 设置 | 音高、共鸣、算法；设备请在「高级实时面板」选 |
| 其他 | 浏览器 WebUI（训练翻唱）、打开目录、再开启动器 |

### 实时变声（开黑）

1. 导入或选择音色  
2. 在「设置」里选好：  
   - **输入** = 真实麦克风  
   - **输出** = **CABLE Input**  
   - 音高 / 其它参数可按需调（运行中多数参数可热更新）  
3. 点底部 **「开启变声」**（后台无第二窗口；首次加载约 20–40 秒）  
4. 游戏 / 语音软件麦克风选 **CABLE Output**  
5. 需要排错时：设置里 **「打开原版实时面板」**（可选，不是日常必用）

### 翻唱 / 训练

「其他」→「打开训练 / 翻唱 WebUI」→ 浏览器 `http://127.0.0.1:7897`（后台启动，无黑框）。

## 4. 和视频的差异说明

| 视频 RVCMAX | 本仓库 |
|-------------|--------|
| 内置大量二次元封面模型 | 你自行导入 `.pth`（可放同名 png 作封面） |
| 闭源美化壳 | 开源壳 + 原版 RVC 引擎 |
| 完整 Runtime 数 GB | 需自备 `Runtime` 或系统 Python + 依赖 |

引擎仍是 RVC；产品路径按大众包重做。

## 5. 打包 exe（给最终用户）

```bat
scripts\build_launcher_exe.bat
```

会生成无控制台的 `启动器.exe`（推荐）与可选主程序打包。  
完整「免 Python」仍建议附带官方/自建 `Runtime` 目录。

## 6. 显卡（NVIDIA / AMD）

对齐官方 RVC：

| 显卡 | 加速方式 | 本软件 |
|------|----------|--------|
| NVIDIA | CUDA | 默认 **auto** 会优先 CUDA |
| AMD / Intel | DirectML（官方 `--dml`） | **auto** 在无 CUDA 时尝试 DML；也可在设置里选 `dml` |
| 无独显 | CPU | 能跑但实时变声很慢 |

当前发行包 Runtime 以 **NVIDIA CUDA** 为主，并内含 DirectML 相关库（与参考 N 卡整合包同源）。  
设置页 **「加速后端」**：`auto` / `cuda` / `dml` / `cpu`。改完后请停止变声再开。

开发调试 A 卡路径：`scripts\dev\go-realtime-gui-dml.bat`、`go-web-dml.bat`（会传 `--dml`）。

## 7. 常见问题

**启动器打不开**  
- 安装 [VC++ 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)  
- 确认有 `pythonw` 或 `Runtime\pythonw.exe`  
- 杀软误报时添加信任

**只有黑框**  
- 不要直接双击旧的 `go-web.bat`（那是开发者模式）  
- 请用 `启动器.vbs` / 桌面快捷方式 / `启动软件.vbs`

**没声音 / 对方听不到变声**  
- 是否安装 VB-Cable  
- 输出是否选 CABLE Input，软件麦克风是否选 CABLE Output  

**AMD 卡很慢或报错**  
- 设置 → 加速后端选 `dml`，停止后重新开启变声  
- 仍不行：确认 Runtime 内有 `torch_directml`（完整发行包）
