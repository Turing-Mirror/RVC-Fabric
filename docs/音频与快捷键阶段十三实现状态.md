# 音频与快捷键阶段十三实现状态

更新于 2026-09-24，分支 `tm-release`。本阶段接续[阶段十二](音频与快捷键阶段十二实现状态.md)。

## 已实现

- 增加独立的语音音频总音量与静音状态，默认 100%、未静音；保存在应用配置中。以 10% 为一步，在 0% 至 100% 范围内调整；升降音量会解除静音，切换静音保留原音量。
- 播放中的各音频实例按“条目音量 × 总音量”更新增益，不重启输出设备，不改变麦克风支路或本地试听。后续新实例沿用当前总音量与静音状态。
- 音频页增加总音量显示、升降与静音控制。动态快捷键新增相同三个动作，默认均不绑定；变化向页面广播，八语言文案同步。

## 验证

- 音量持久化与静音保留音量的 Rust 定向测试通过；前端页面控制测试通过。
- TypeScript、相关组件 ESLint、八语言检查及 Windows 目标静态编译通过。
- 当前 macOS 工作区没有 Windows 虚拟声卡实机环境；即时增益的真实听感、设备恢复和全局快捷键仍需用户在 Windows 验收。

## 仍待完成

- 重播、循环和拖动进度尚未接入播放器实例；旧九项系统占用组合键时的注册失败回滚，以及设置页进一步分组、筛选仍待处理。
