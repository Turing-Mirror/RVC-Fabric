# 发行版打包与用户使用

## 目标体验

用户拿到压缩包后：

1. 解压  
2. 双击 **`启动器.exe`**  
3. 发送快捷方式 + **安装虚拟声卡**  
4. 桌面图标 / **`变声器.exe`** 日常使用  

**不需要**自装 Python、不需要双击 bat、不需要自己下 hubert（若打包机已打入 Runtime 与模型）。

开发阶段用仓库根目录 `start.bat` / `start_app.bat`（转到 `scripts/dev/`；有 exe 则优先 exe）。

---

## 开发机：免装系统依赖做 bat 测试

RVCMAX 参考包已含 Runtime / hubert / rmvpe / ffmpeg / 模型 / VBCABLE。在仓库根执行：

```bat
scripts\sync_from_rvcmax.bat
```

会：

- 把 hubert、rmvpe、ffmpeg、预置模型、VBCABLE 拷进本仓库  
- 用 **目录联接（junction）** 把 `Runtime\` 指到 RVCMAX 的 Runtime（不占双倍磁盘）  

然后可直接：

```bat
start.bat
start_app.bat
scripts\dev\go-web.bat
scripts\dev\go-realtime-gui.bat
```

均优先用 `Runtime\python.exe`，**不必** `pip install`。

---

## 打包机：一键命令

在仓库根目录（需本机 Python，仅打包用；用户端不需要）：

```bat
scripts\sync_from_rvcmax.bat
scripts\build_release.bat
```

或：

```bat
python scripts/build_release.py --clean
```

可选参数：

| 参数 | 含义 |
|------|------|
| `--runtime PATH` | 绿色 Python 目录（含 `python.exe`） |
| `--models PATH` | 预置音色（`User_Data/models` 或若干 `.pth`） |
| `--vbcable PATH` | VB-Cable 安装包目录 |
| `--skip-exe` | 只组目录不打 PyInstaller |
| `--skip-runtime` | 不拷 Runtime（调试用，**勿这样发用户**） |
| `--out PATH` | 输出目录，默认 `dist/RVC-Fabric` |

默认会尝试从本仓库旁的参考包读取：

`RVCMAX/RVCMAX_Nvidia_xiaoyuan/{Runtime,User_Data/models,VBCABLE}`

---

## 输出目录结构

```
dist/RVC-Fabric/
  启动器.exe          ← 用户首次入口
  变声器.exe          ← 日常入口（快捷方式指向它）
  Runtime/            ← 内嵌环境（必须）
  User_Data/models/   ← 预置模型（必须有至少一个才「开箱能变」）
  VBCABLE/            ← 虚拟声卡（用户只需点安装）
  assets/ infer/ …    ← 引擎
  launcher/           ← 源码回退
  使用说明.txt
  tools/dev/*.bat     ← 仅开发，勿当用户文档推荐
```

把 **`RVC-Fabric` 整个文件夹** 打成 7z/zip 分发即可。

---

## 入口兼容关系

| 场景 | 入口 |
|------|------|
| 发行版用户 | `启动器.exe` → 桌面快捷方式 → `变声器.exe` |
| 开发未打 exe | `start.bat` / `start_app.bat` / VBS + 系统或 Runtime Python |
| 目录里已有 exe | `start.bat` 自动 `start 启动器.exe` |

`launcher/paths.py`：frozen 时 ROOT=exe 所在目录；`find_python` **优先 Runtime**。  
`win_util.create_desktop_shortcut` / `start_main_app`：**优先变声器.exe**。

---

## 体积与注意

- Runtime + 模型通常 **数 GB～十余 GB**，属正常。  
- 打包机需足够磁盘；`robocopy` 拷 Runtime。  
- 勿把 `RVCMAX/` 参考包整份提交进 git（已 gitignore）。  
- 合规：VB-Cable 保持官方安装包；预置模型确保你有分发权。
