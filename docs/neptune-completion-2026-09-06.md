# Neptune 功能收尾记录

本次只修改 Neptune 分支，不修改主分支，不提升版本号，不创建发行版。

## 三张看板的落实情况

| 项目 | 实现和核查结果 |
| --- | --- |
| 故障设备恢复 | 启动报错横幅可检查并忽略失败的已选设备，再重新配置和启动。按接口、名称和输入/输出方向保存排除项。设置页可以恢复单个设备，也可以关闭、重新启用排除列表。 |
| ASIO 枚举崩溃 | 设置页和故障横幅提供非 ASIO 兼容模式。使用独立 DLL，不修改注册表或卸载系统驱动。首次启用需下载组件。 |
| 输入音频剪辑 | 语音转换输入区域支持起止时间、滑块、选段试听和另存片段。原文件不变。 |
| 模型导出与分享 | 模型菜单提供 ZIP 导出和分享信息复制。包内包含权重、已绑定索引、本地封面、默认参数和命名档案，可重新导入。不会自动向 QQ 发消息或上传文件。 |
| 背景图可读性 | 保留分支现有的背景图取色和表面透明度适配，不改变无背景图时的默认样式。 |
| 悬浮窗 | 名称随音色选择、改名和 DSP 预设变化更新。悬停提供启停和旁路控制；名称更新使用事件，不反复扫描模型库。 |
| Web 快捷键 | 主窗、工具窗和悬浮窗均配置 WebView2 快捷键限制；前端同时拦截 F9、刷新、查找、打印等默认行为。保留输入编辑和应用自定义快捷键，包括 Ctrl+F9。 |
| 自动配置音频 | 保留并核查已有 MME、麦克风和 CABLE Input 配置逻辑，恢复流程复用同一选择函数，不覆盖仍有效的手动配置。 |
| Realtek 提示过敏 | 不再以任意引擎崩溃作为音频枚举失败的证据；必须有独立音频探测崩溃记录。文案不再仅凭已安装 Realtek 驱动便归因于它。探测超时会回收子进程。 |
| 模型改名、封面裁剪 | 保留现有功能，限制裁剪输出长边为 2048，避免极端长宽比造成过大的画布。 |
| 资源不足误判 | 核查现有启动宽限期、连续欠载窗口和用户确认流程；没有新增自动替换 RMVPE 的行为。 |

## 前序提交的接线修复

- 音高纠错进入无界面引擎的配置读取、热更新和音色切换路径，默认仍关闭。
- 预加载直接读取保存的音色参数，不依赖首次启动前尚未初始化的 GUIConfig；检查实际运行标志。
- 离线转换在降低 GPU 占用后仍发生 OOM 时继续尝试 CPU。借用实时模型的热路径不会移动实时模型，而是交给独立进程处理。
- 咨询包固定一次参数快照，传递响度混合和保护参数，记录各语言失败原因。界面和包内声明其为离线基线，不冒充包含实时共振峰和音效的结果。
- 补齐八种语言的新文案，以及降级原因和档位名称的翻译。新增组件订阅语言变化。
- 配置恢复会创建缺失的 inuse 子目录。旧测试改为检查当前单例包装和 WSOLA 子对象的实际接口。
- 原有文字合成复用、块几何复用和卸载保留用户数据逻辑继续保留。

## 性能与安全检查

模型包和咨询包中的音频采用流式写入，不整段加载到内存。模型导出先生成同目录临时包，再原子替换目标文件。导出元数据使用允许列表，排除运行日志和本机模型路径。音频裁剪直接调用 FFmpeg，不经过 shell，并限制输入协议为本地文件和管道。声卡兼容组件下载校验固定 SHA-256，提取指定 DLL 和许可文件。

兼容组件来源为 [sounddevice 0.5.2 官方 PyPI 元数据](https://pypi.org/pypi/sounddevice/0.5.2/json)。非 ASIO DLL 的文件名和包内路径已与[官方打包代码](https://github.com/spatialaudio/python-sounddevice/blob/0.5.2/setup.py)核对。没有升级用户现有的 sounddevice Python 绑定。

## 验证与边界

- 前端生产构建、ESLint、TypeScript 和八语言结构、占位符、引用检查通过。
- 前端 Vitest：42 项通过。
- Rust 单元测试：353 项通过，其中包含模型包导出后重新导入、设备排除开关和动态翻译测试。
- Windows GNU 目标的 `cargo check --offline --target x86_64-pc-windows-gnu` 通过。
- 系统 Python 的 unittest 全量发现：526 项，506 项通过、20 项因依赖或硬件条件跳过。
- 另用带 Torch 的验证环境运行受本次修改影响的引擎、配置恢复、消息协议和录音测试。该环境没有 NumPy，不以它运行整个 DSP 测试集。
- Codex 内置浏览器检查了新增组件的真实渲染、语言刷新、范围编辑和应用回调。组件验证使用合成 WAV 和模拟桌面命令，不等同于 Windows 原生调用测试。临时验证页面已移除。
- 引擎负载准备及忽略规则检查通过，新增音频后端模块包含在负载中。

尚需 Windows 实机验证：故障 ASIO 驱动隔离、物理声卡与 VB-Cable 开流、WebView2 原生快捷键行为、FFmpeg 实际文件裁剪，以及固定模型的 GPU 声音基线。本机没有对应 Windows Runtime 或 FFmpeg，且访问 PyPI 文件 CDN 的 TLS 握手失败，因此没有把这些项目记录为实测通过。构建和交叉编译不替代这些验证。
