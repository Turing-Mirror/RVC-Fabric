# 在线更新与音色库

## 能做什么

| 场景 | 方式 |
|------|------|
| **软件内** 更新 GUI 本体 | 下载 zip 补丁（GitHub Release / SharePoint 直链）→ 仅覆盖允许的壳层文件 |
| **软件内** 下载音色 | 清单中的 `pth_url`（+ 可选 index/cover）→ `User_Data/models/<id>/` |
| **软件外** 完整包（Runtime / 显卡分版） | SharePoint 链接 或 QQ 群（打开浏览器，不在进程内解压 Runtime） |

对齐原版 RVC「资源从网上下」的思路，分发渠道改为 **SharePoint 直链 / GitHub 直链**，完整大包仍走群或网盘。

## 用户界面

主界面导航 **「更新」**（`launcher/ui/store_page.py`）：

1. **检查更新** — 拉取远程 catalog JSON  
2. **下载并应用 GUI** — 有新版本且配置了 `gui.url` 时可用  
3. **在线音色库** — 列表下载安装  
4. **SharePoint 完整包 / QQ 群** — 外链  

## 清单文件

### 本地默认

`configs/online_catalog.json`（随包分发，可改）

### 远程覆盖

`app_config.json` 字段 `update_manifest_url`，或 catalog 内 `manifest_urls` 数组。

远程 JSON 结构与本地相同。成功拉取后缓存到 `User_Data/update_cache/catalog.json`。

### 字段说明

```json
{
  "schema": 1,
  "app": {

    "channel": "stable",

```

## 直链要求

### GitHub

- Release：`…/releases/download/tag/file.zip`  
- Raw：`raw.githubusercontent.com/...`  
- `blob` 链接会在下载前自动转 raw  

### SharePoint / OneDrive

- 使用**任何人可访问**的共享链接  
- 建议链接带 `download=1`，或公开分享后由客户端尝试解析 `download.aspx`  
- **需要登录的租户链接无法在软件内静默下载**  

## GUI 补丁 zip

相对**软件根目录**的路径，例如：

```text
launcher/main_app.py
launcher/theme.py
configs/online_catalog.json
```

**禁止覆盖：** `Runtime/`、`User_Data/`、`assets/hubert|rmvpe|pretrained…`、`VBCABLE/` 等。  
本地版本号见 `launcher/version.py` 的 `APP_VERSION`。

## 代码位置

| 模块 | 职责 |
|------|------|
| `launcher/online/downloader.py` | HTTP + SharePoint/GitHub 解析 |
| `launcher/online/catalog.py` | 清单读写 / 合并 / 缓存 |
| `launcher/online/voice_install.py` | 音色安装到 User_Data |
| `launcher/online/gui_update.py` | zip 安全解压 |
| `launcher/ui/store_page.py` | UI |
| `launcher/version.py` | 本地版本 |

## 运营侧清单

1. 填好 `configs/online_catalog.json` 的 QQ / SharePoint / 音色直链  
2. 可选：把同一 JSON 放到 GitHub raw 或 SharePoint，并写入 `manifest_urls`  
3. 发 GUI 时：升 `APP_VERSION`、打 zip、填 `gui.url`  
4. 完整 Runtime 包仍只走 SharePoint / QQ 群，不在软件内热更
