## 实际运行

使用独立配置根目录和真实 Serika_ZH 模型、CUDA 推理，关闭所有硬件输出，连续运行 300 秒。收到 15,205 个网络音频帧，其中 15,019 个非零；丢帧计数为 0，测得最大处理耗时 157 ms。此数值是当前机器上的推理时间，不是端到端延迟或听感评价。

发布程序通过插播播放、暂停、定位、循环、增益和停止测试。关闭麦克风停止推理并保留连接，重连凭据和撤销凭据行为通过。真实 WAV 上传、RVC 文件转换、结果下载、取消任务，以及其他设备不能读取任务和文件的验证通过。

Android 模拟器通过覆盖升级、二维码图片配对、已记住电脑重连、显式开启录音、关闭麦克风与电脑状态同步。扫码相机入口能够请求权限；扫码解析另有真实二维码编解码测试。物理相机识别、Magisk／LSPosed／Shizuku 目标应用注入及主观音质仍需对应实体手机验收。

## 首页卡片

旧实现用模型目录作为 React key 和 FLIP 动画标识，同目录多个模型会共享身份。在实际窗口中复现了三卡区域累积为六个节点。修复后使用模型文件身份，去除重复模型记录，并阻止过期的异步读取覆盖新结果。

修复后的真实窗口往返首页十二次，每次保持三张卡片和三个不同身份；静止时三张卡片均没有残留换位动画。原有布局和切换动画保留。
