# 音频与快捷键阶段十一实现状态

更新于 2026-09-24，分支 `tm-release`。本阶段接续[阶段十](音频与快捷键阶段十实现状态.md)。

## 已实现

- 新增“停止试听”动态快捷键动作。动作默认不绑定，使用现有录制、作用域、注册和后台分发流程，八语言文案同步。
- 保存音频快捷键时检查目标条目是否仍在音频库，避免旧页面把已删除条目的绑定重新写回。
- 删除音频来源时，仅移除真正失去条目的播放绑定；仍由其他来源引用的音频及其绑定保持不变。音频库与绑定更新按固定顺序串行处理，写入失败不报告删除成功。注册状态与两个编辑入口随后同步刷新。

## 验证

- 前端 TypeScript、i18n 检查、快捷键定向测试和组件 ESLint 通过。
- Rust 的绑定过滤、独占来源删除和重叠来源保留测试通过；Windows 目标静态编译通过。
- 本机缺少安装包所需的 `ffprobe.exe` 等 Windows 资源，测试时仅在 Cargo 进程中关闭资源打包配置；未修改产品配置或创建假可执行文件。Windows 实机出声、设备与全局快捷键行为仍待用户验收。

## 仍待完成

- 重播、循环、音量增减、静音和拖动进度尚未接入播放器实例；不能将这些动作显示为可绑定而实际无法执行。
- 旧九项与音频绑定双向编辑时的原子冲突处理，以及设置页进一步分组、筛选仍未完成。
