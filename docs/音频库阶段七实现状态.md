# 音频库阶段七实现状态

更新于 2026-09-23，分支 `tm-release`。本阶段接续[阶段六](音频库阶段六实现状态.md)。

## 已实现

- 悬浮窗读取原生语音输出的播放状态；有音频时显示名称、片段相对进度和暂停、继续、停止控制。变声未运行时，音频状态仍能独立显示。
- 有音频时悬浮窗增高，无音频时恢复原有紧凑高度；增高后按当前屏幕工作区修正位置。音频播放期间不会因麦克风安静而整体淡出。
- 控制键在鼠标悬停或键盘聚焦时显示；关闭悬浮窗仅关闭窗口，不停止音频。音频页与悬浮窗复用同一播放状态类型和时间格式辅助函数。

## 待继续

- 本阶段仍只有一个音频实例；多实例计数、独立停止、循环与拖动定位需要先完成原生多实例播放合同。当前进度条是只读显示。
- 窗口尺寸与多屏、DPI、游戏覆盖效果尚待 Windows 实机确认；本机仅完成静态编译、类型与文案检查。
