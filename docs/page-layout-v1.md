## 自定义内容首帧修复（2026-11-08）

首页、设置页共享当前窗口最近读取的配置快照。切回页面时同步读取快照，后台再刷新；首次加载尚未读取配置时，不显示默认横幅冒充用户内容。清空自定义标题后仍正常显示默认标题。

本地待保存修改、成功保存和其他窗口的 config-changed 事件均更新快照。较早发出的读取或写入响应不能覆盖较新的字段；保存确认即使没有改变乐观显示值，也会推进字段版本。读取失败时保留已知内容。所有窗口从入口订阅配置事件，页面离开后仍可接收更新。

RVCF 的模型页 DSP 使用中标记也从配置快照初始化。原有页面布局与切换动画保持不变。

## 草稿、试听与列表首帧补充修复（2026-11-08）

RVCF 没有 GPT-SoVITS 的数据标注页。本次核查其实际同类问题：文字合成的未提交文本、朗读音色、语速、音高和转换开关由工具面板保留，在顶部切换音频变声与文字合成后恢复。草稿只保留在当前工具窗口，不新增自动合成、文件保存或退出确认。

音频变声试听捕获 `HTMLMediaElement.play()` 的拒绝，播放失败后清理状态并使用原有错误提示。每次试听使用独立媒体对象，停止、换曲和卸载后，旧播放 Promise 与结束事件不能改写当前状态。删除或改名时同时识别原声与转换后版本；筛选、分页、排除或刷新导致试听条目退出当前列表时停止播放。音频裁剪切换输入、关闭、播放失败和自然结束均清理试听状态，旧输入的播放拒绝或裁剪结果不影响新输入。停止或卸载试听会移除媒体 source 并调用 load 释放资源；删除和改名前也清理尚未完成的播放请求，并关闭同文件的裁剪编辑器。裁剪预览在下一次播放时恢复 source，输入切换与 StrictMode 清理不会误清新音源。

模型页同步使用已有音色目录快照，训练队列同步使用当前窗口最近一次原生队列快照，并继续后台刷新。首次读取尚未完成时不显示未经确认的空列表文案；已有数据刷新失败时保留内容。队列的较早读取不能覆盖更新事件，卸载前发出的读取不能覆盖重新挂载后的快照。列表布局、分页和切换动画保持原样。

验证：50 个前端测试文件、285 项测试通过。新增 15 项回归覆盖首次读取、缓存返回与读取失败、卸载旧队列响应、文字草稿切换、试听拒绝/换曲/停止后的迟到回调、筛选与翻页停止试听、删除转换后试听，以及裁剪切换输入、关闭和旧结果。删除与改名测试在模拟原生文件操作前断言媒体 source 已释放；额外覆盖裁剪媒体元素再次使用和 StrictMode。lint、TypeScript、八语言文案检查和完整构建（含引擎 payload）通过。Vite 仍报告现有混合导入和主包体积提示；测试均模拟原生接口，没有真实训练、合成或用户文件删除，也未停止或重启运行中的实例。
