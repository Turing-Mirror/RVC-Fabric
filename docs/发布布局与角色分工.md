# 发布布局与角色分工（对齐 RVCMAX · 视觉属 Turing Mirror）

> **布局/角色** 参考 RVCMAX 发布包的岗位划分。  
> **界面气质** 遵循 `docs/UI-AESTHETIC-DESIGN.md`「白无垢」，**不**照抄 RVCMAX 粉紫卡片。  
> 产品定位：与 **Turing Mirror** 网站配套的本地变声器。

---

## 1. 角色分工（与 RVCMAX 同构）

| 角色 | RVCMAX 包 | 本仓库 / 发布物 |
|------|-----------|-----------------|
| 首次启动器 | `启动器.exe` | **发行：** `启动器.exe`　**开发：** `start.bat` / `bootstrap.py` |
| 日常主程序 | `RVCMAX/RVCMAX.exe` | **发行：** `变声器.exe`　**开发：** `start_app.bat` / `main_app.py` |
| 引擎核心 | `RVC_Core/` | 仓库根（`infer*`、`assets` 引擎权重） |
| 用户数据 | `User_Data/` | `User_Data/`（模型目录、配置、日志） |
| 虚拟声卡 | `VBCABLE/` | `VBCABLE/` |
| 绿色 Python | `Runtime/` | `Runtime/` 或 `runtime/`（可选；未打包时用系统 Python） |
| 高级/开发 | — | `go-web.bat` 等（**非**默认入口） |

### 推荐用户动线（发行版）

1. **首次**：双击 **`启动器.exe`** → 发送桌面快捷方式 / 安装虚拟声卡（环境与模型已在包内）  
2. **日常**：桌面快捷方式或 **`变声器.exe`**  
3. **高级**：主界面「其他」→ WebUI  

开发动线见 `docs/发行版打包与用户使用.md`（bat 仅开发）。一键打包：`scripts\build_release.bat`。

## 2. 用户数据（产品故事）

```
User_Data/
  app_config.json
  models/
    <音色名>/
      *.pth
      cover.png          # 可选
      config.json        # 可选：name, tag, pitch, formant, index
  logs/
  indices/               # 可选
```

- 引擎必备：`assets/hubert`、`assets/rmvpe` 等仍在引擎侧。  
- **不要**把「只往 `assets/weights` 丢 pth」当作唯一产品说明；导入默认写入 `User_Data/models`。  
- 兼容：仍扫描 `assets/weights/*.pth` 作为 legacy 列表。

## 3. 视觉（白无垢 · 非 RVCMAX）

| 要 | 不要 |
|----|------|
| 暖纸画布 `#f4f1ea` | 粉紫卡片主色 |
| 素墨强调 `#1c1a17` | 蓝紫渐变 / 霓虹 |
| 衬线刊头 + 系统无衬线正文 | 营销口号堆砌、emoji 装饰 |
| 中文优先、短工具向文案 | 「永久免费!!」式喊麦文案 |

令牌实现：`launcher/theme.py`（与手册 light token 对齐）。

---

## 4. 无黑框入口

| 入口 | 作用 |
|------|------|
| `start.bat` | wscript → `launcher/run_hidden.vbs bootstrap` |
| `start_app.bat` | wscript → `… app` |
| `一键启动.bat` | 转发 `start.bat` |
| 桌面快捷方式 | 指向 `run_hidden.vbs app` |

路径含空格（如 `My project`）时请用上述入口，勿手写未加引号的 cmd 拼接。

---

## 5. Runtime 说明

完整绿色 `Runtime` 体积大，可不随源码仓库提交。发布 zip 时再放入；启动器会检测 `Runtime/pythonw.exe` 并回退系统 Python。
