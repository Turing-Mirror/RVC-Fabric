## 角色对应

| 角色 | 目录 |
|------|------|
| 产品 UI | `launcher/` |
| 引擎 | 根下 `infer*`、`assets`、`configs`、`gui_v1.py` |
| 用户数据 | `User_Data/` |
| 虚拟声卡 | `VBCABLE/` |
| 打包 | `scripts/build_release.*` |
| 开发启动 | `scripts/dev/` + 根目录薄 bat |

## Git 仓库含什么 / 不含什么

详见 **[`docs/仓库内容说明.md`](仓库内容说明.md)**。

摘要：

- **进 Git**：源码（`launcher/`、`infer/`、`gui_v1.py`…）、文档、打包脚本、依赖清单。  
- **不进 Git**：`Runtime/`、`dist/`/`build/`、大预训练权重、ffmpeg 二进制、用户音色与本机配置/日志等。  
- **用户到手的完整包** 由 `scripts/build_release.py` 在打包机上组装，不是 `git clone`  alone。

## 不要

- 不要把本机 `dist/`、`_local/`、完整 `Runtime` 当源码主树去改仓库  
- 不要把 `scripts/dev/*.bat` 写成用户手册主入口（发行用 exe）
