# 音频与快捷键阶段十五实现状态

更新于 2026-09-24，分支 `tm-release`。本阶段接续[阶段十四](音频与快捷键阶段十四实现状态.md)。

## 已实现

- 裁剪波形：峰值从每秒 24 格提到 400 格，改为连续包络绘制，最大放大到 4000px/s 也不再是稀疏竖线。滚轮缩放按滚动量计算，一格约 1.3 倍；Shift+滚轮或触控板横滑左右移动，提示里写明。删除语音转换裁剪器下方的播放位置和起止滑块，由拖波形和起止输入框代替。
- 循环：条目可设“默认循环播放”，播放中的实例可单独切换，快捷键新增“切换循环”。循环在最后一帧播出前都能开关，关掉后播完当前这一遍。
- 拖动进度：活动实例的进度条可拖动或用方向键定位，只在片段范围内跳转，保留暂停和循环状态。
- 淡变：起播、暂停、继续、停止、替换都有 8ms 包络，停止和替换先淡出再换槽；片段首尾和循环接缝各有 5ms 淡变。
- 重播：“重播当前音频”在没有活动实例时重播最近一首。
- 本地监听：语音内播放的音频同时送到音频页选择的本地输出，与语音输出同步暂停、停止、拖动、循环和音量；本地设备缺失或失败只丢掉本地这一路。音频页可关闭。
- 旧九项快捷键：保存时实际注册，被系统或其他软件占用则恢复原组合并提示；旧九项之间的重复组合在写盘前拒绝；每行显示已生效、仅本软件、冲突等状态。
- 设置页快捷键分为“变声”“音频播放”“编号音频”三组，一个搜索框同时筛选。同页两个音频绑定编辑器基于最新保存列表修改，不会互相覆盖。

## 验证

- 前端：TypeScript、ESLint、八语言检查通过，Vitest 35 个文件 203 项通过。
- Rust：音频、快捷键相关测试全部通过；整库在 macOS 上 421 项通过，27 项失败均在 STS 来源与 worker 模块，本阶段未改动这些文件，属于既有的平台差异。
- 解码器集成测试用真实 FFmpeg 跑通 6 项，包括首遍偏移、多遍循环、中途开关循环和边缘淡变。
- 浏览器实测波形：全览、放大到上限、Shift+滚轮与横滑平移、拖选区间、进度条拖动提交均正常。
