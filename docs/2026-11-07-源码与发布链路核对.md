## 产品当前结构

React / TypeScript 前端提供七个主页面、工具窗口和悬浮窗；Tauri / Rust 管理配置、进程、资源下载、音色、音频库与更新。Python 承担实时 RVC / DSP、STS、训练和分离。TTS 原声由 Windows SAPI 合成，可选 RVC 阶段再进入 Python 转换。

实时控制采用带序列号的 JSON 文件协议，离线任务另有进度文件或 stdout JSON 行；音频 PCM 由共享内存及有界缓冲传递。`fabric-audio` 通过 FFmpeg / ffprobe 子进程解码，通过 CPAL 输出；它不替代 Python 的 RVC 推理和所有输入设备流程。

`tools/realtime_block.py` 集中公共分块算法，实时回调和 `OfflineStream` 复用它。普通 STS 仍是文件转换路径，不能用它代替完整实时处理链。CPU 假模型的一致性测试只证明受测配置，不是 GPU、声卡、监听和混音的完整验收。

## 发布仓与客户端的对应关系

发布仓是清单仓。大型安装包、运行环境和权重位于 CNB Release 附件；Git 只跟踪维护资料、YAML、JSON、封面和 SHA-256 边车。第三方音色仍从来源站下载。

| 维护对象 | 入口与行为 |
| --- | --- |
| 外壳、安装包 | `catalog-src/setup.yaml`、`app.yaml`；当前 `full_package` 是完整 NSIS 外壳安装包，仍不包含 Python Runtime 和大模型 |
| Runtime | `runtimes/{nvidia,nvidia50,amd}.yaml`；客户端在线规格优先，失败用内置 fallback |
| engine-core / VB-Cable / audio-tools | 发布元数据与客户端 `engine_assets.rs` 的固定文件名、SHA 必须协调；只改发布 YAML 不会改变已安装客户端的固定哈希 |
| 官方/第三方音色 | `voices/`、`thirdparty/`；第三方结构验证为发布门槛，草稿目录不编入正式清单 |
| 分离/训练资源 | `extras/`；Release 使用文件基名寻址，本地路径由 `dest` 和 `files[].name` 决定；PyMSS YAML 随产品下发，权重走附件 |
| 广场/更新记录 | `plaza.yaml`、`changelog.yaml`；最新 changelog 派生 `app.gui.notes` |
| OTA 签名 | `updater.json` 单独维护，不由清单编译器生成；版本名 URL 与产品内置公钥验签配合使用 |

`scripts/build_catalog.py` 从 YAML 生成五份 JSON：发布仓 `index.json`、`catalog/online_catalog.snippet.json`、`plaza.json`、`changelog.json`，以及产品仓 `configs/online_catalog.json`。有锁定哈希/大小时，以已发布锁定值为准；本地缓存漂移普通模式给警告，`--strict` 才判失败。

`publish_asset.py --write-yaml` 只更新顶层哈希、大小、制品通道和标签，不自动改版本、日期、嵌套的 `gui` / `parts` / `files`。嵌套 YAML 的边车也需要单独核对。旧文档中的 LFS 下载、封面只放 Git、PyMSS 同时上传 YAML、删除 `build_setup.py` 等示例不能直接沿用：当前 NSIS 负载仍依赖该脚本的组装函数。

客户端主清单先取 `index.json`，再取兼容清单，成功结果有 300 秒缓存；手动检查可绕缓存。推送清单不等于所有客户端立刻刷新，更不等于重新发布安装包。

## 本轮代码修正与验证

本轮源码核读发现并处理三处局部问题：

1. 波形缓存按最多 720000 个峰值写出，却拒绝读取超过 128 KiB 的文件。将读取上限按峰值上限和 JSON 编码大小计算，避免几分钟音频反复调用 FFmpeg 生成同一波形。
2. 安装器按字符串前缀结束进程，会将 `C:\RVC-other` 误认成 `C:\RVC` 内部进程。现在按带分隔符的目录边界匹配，并通过环境变量传入路径，避免单引号进入 PowerShell 源码。
3. 高级 WebUI 的普通启动路径原来监听所有网卡，与桌面入口的 `127.0.0.1:7897` 定位不一致。普通启动改为 loopback；显式 Colab 分享路径保留。

验证结果：

- 发布、版本、安装器、音频负载、构建变体和 WebUI 的 Python 回归共 63 项，62 通过、1 因缺少旧 RVCMAX 参考包跳过。
- 两项 Rust 波形测试通过。新增 4 分钟和 1 小时缓存读写回归在修复前失败、修复后通过；仍有 `worker.rs` 既有测试局部变量未使用警告。
- 安装器目录匹配在 PowerShell 5 中用模拟进程验证，覆盖同名前缀目录、大小写、末尾分隔符和含单引号路径；没有停止真实进程。新宏的最小 NSIS 编译检查通过，仅有其他钩子变量未使用警告。
- 本次没有重跑全部 Python / 前端 / Rust 测试、生产打包或真实设备音频验收，不能用历史发版的全套测试数量代替本次结果。

本轮没有提升产品版本、重新构建正式安装包或上传制品。这些修正将在后续正式发版后到达安装用户。
