# 与 B 站 RVCMAX 发布目录对照

视频：[BV1WVzYBcE2K](https://www.bilibili.com/video/BV1WVzYBcE2K)

## 视频中的包

```
RVCMAX_Nvida_yc/
  Runtime/          绿色 Python
  RVC_Core/         引擎
  RVCMAX/           美化主程序
  User Data/        用户数据
  VBCABLE/          虚拟声卡
  启动器.exe         源星启动器（快捷方式/声卡/远程）
```

桌面快捷方式 → 白净主界面（首页轮播 / 模型库 / 设置），**不是黑框**。

## 本仓库对应关系

| 视频 | 本仓库 |
|------|--------|
| 启动器.exe | `启动器.vbs` / `启动器.exe`（`launcher/bootstrap.py`） |
| RVCMAX 主程序 | `launcher/main_app.py` → `启动软件.vbs` / `RVC变声器.exe` |
| RVC_Core | 根目录 `infer*`、`configs`、`assets`… |
| Runtime | `Runtime/` 或 `runtime/`（自备） |
| User Data | `UserData/` |
| VBCABLE | `VBCABLE/` |
| 桌面快捷方式 | 启动器内「发送快捷方式」 |

## 用户动线（必须一致）

1. 解压到非中文过深路径（推荐 `C:\RVC\`）  
2. 双击启动器（粉白三卡片）  
3. 发送快捷方式 + 安装虚拟声卡  
4. 桌面图标打开主软件  
5. 选模型 → 开变声 → 游戏选 CABLE Output
