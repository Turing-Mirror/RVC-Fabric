# 音频与快捷键阶段十实现状态

更新于 2026-09-24，分支 `tm-release`。本阶段接续[阶段九](音频与快捷键阶段九实现状态.md)。

## 已实现

- 音频快捷键改为动态绑定列表，按稳定的音频条目 ID 指向素材。支持替换或叠加播放、暂停或继续最近播放、停止最近播放、停止全部音频，以及打开音频页；默认不占用新组合键。
- 设置页和音频条目页共用绑定编辑器。可添加、录制、清除、移除，以及设置全局或仅窗口内生效。旧九项保留原配置；清除旧组合键不会恢复默认值。
- 前后端共用键位规范。录制范围扩展到小键盘、方向与导航键、标点、媒体键等可由插件解析的键；录制期间抑制全局与窗口内触发，退出录制后恢复。
- 全局绑定由原生后端执行，主窗口隐藏时不依赖页面监听；窗口内绑定调用相同音频命令。注册器差量更新，给音频绑定返回生效、窗口内、未绑定、未启用或冲突状态；音频新绑定注册失败时恢复上一次保存的配置。

## 尚未完成或尚未验证

- 计划中的重播、循环、音量增减、静音和停止试听动作，以及设置页进一步按动作类别分组与查询筛选。
- 删除音频来源后关联绑定的自动清理、旧九项与音频绑定双向编辑时的原子冲突处理，还需补齐。
- Windows 实机的全局键位、系统占用、输入法、设备出声与隐藏窗口行为待用户回到 Windows 后验收。静态编译与模拟测试不等于实机通过。
