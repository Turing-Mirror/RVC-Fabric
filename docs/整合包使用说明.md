# RVC 整合包使用说明（B 站 / 官方同款流程）

本仓库按 **「花儿不哭 / 官方 RVC 整合包」** 在 B 站教程里的用法来组织入口：

> **双击启动 → 浏览器打开 WebUI（或实时变声窗口）**  
> 界面仍是原来的 Gradio RVC，不是另做一套花哨壳。

官方演示视频可参考：[RVC 变声器官方教程（花儿不哭）](https://www.bilibili.com/video/BV1pm4y1z7Gm/)

---

## 1. 你要的那种「长什么样」

B 站热门教程里，大家用的几乎都是同一套：

| 步骤 | 做什么 |
|------|--------|
| 解压 | 路径尽量 **英文、无空格**（如 `D:\RVC\`） |
| 双击 | `go-web.bat` 或本仓库的 **`一键启动.bat`** |
| 浏览器 | 自动打开 `http://127.0.0.1:7897`（端口以窗口提示为准） |
| WebUI 标签 | **模型推理** / **伴奏人声分离** / **训练** / **ckpt 处理** |
| 实时变声 | 另开 `go-realtime-gui.bat`，配合虚拟声卡（如 Voicemeeter） |
| 音色 | 把别人的 `.pth`（约 55–60MB）丢进 `assets\weights`，点「刷新音色」 |

完整官方整合包（自带 `runtime` 绿色 Python，约数 GB）：

- 资源页：https://huggingface.co/lj1995/VoiceConversionWebUI/tree/main/
- **N 卡**：`RVC1006Nvidia.7z`
- **A 卡 / Intel**：`RVC1006AMD_Intel.7z`
- 旧名：`RVC-beta.7z`

把解压出来的 **`runtime` 文件夹** 整个拷到本仓库根目录，即可获得和 B 站视频完全一样的「免装 Python」体验。

## 2. 本仓库怎么启动（推荐）

### 方式 A：一键启动器（推荐）

1. 双击根目录 **`一键启动.bat`**
2. 在窗口中点：
   - **① 启动 WebUI** → 训练 / 翻唱推理 / UVR 分离
   - **② 启动实时变声** → 游戏、语音通话
   - **下载预训练模型** → hubert、rmvpe、底模等
   - **打开音色文件夹** → 放入 `.pth`

若已用 PyInstaller 打出 **`RVC启动器.exe`**，双击 exe 即可（内部仍是上述逻辑）。

### 方式 B：和官方视频完全一致

| 文件 | 用途 |
|------|------|
| `go-web.bat` | N 卡 WebUI |
| `go-web-dml.bat` | A/I 卡 WebUI（DirectML） |
| `go-realtime-gui.bat` | 实时变声 |
| `go-realtime-gui-dml.bat` | A/I 卡实时变声 |

## 3. 第一次使用检查清单

1. **路径**：不要放在桌面中文路径过深、或含 `&` `()` 的目录  
2. **runtime 或 Python**：有 `runtime\python.exe` 最佳；否则需本机 Python 3.9–3.10 + 依赖  
3. **预训练文件**（点启动器「下载」或自己下）：
   - `assets/hubert/hubert_base.pt`
   - `assets/rmvpe/rmvpe.pt`
   - 训练还要 `assets/pretrained` / `pretrained_v2`
4. **FFmpeg**（Windows 官方包通常自带；否则放到根目录或 PATH）
5. **关代理**：WebUI 报 `Connection Error` 时关掉系统代理（见 FAQ）

---

## 4. 推理（翻唱）——和视频同款

1. 启动 WebUI  
2. 打开 **模型推理**  
3. 推理音色：选 `assets/weights` 里的模型（没有就点刷新）  
4. 上传干声或歌曲人声  
5. 音高：男→女常试 `+12`，女→男试 `-12`  
6. 特征检索库：若有 `.index` 一并选上，`index rate` 常用 `0.5~0.75`  
7. F0 算法：优先 **rmvpe**  
8. 转换 → 下载结果  

人声分离：用 **伴奏人声分离** 标签（UVR5），先出干声再推理。

---

## 5. 实时变声——和视频同款

1. 启动 **实时变声 GUI**  
2. 输入设备：麦克风；输出：虚拟线缆 / 耳机  
3. 加载 `.pth` + `.index`  
4. 输入输出尽量选 **同一种 API**（如都是 MME 或都是 ASIO）  
5. 通话软件选「虚拟声卡输出」作为麦克风  

---

## 6. 训练自己的音色（简述）

1. 准备 ≥10 分钟干净人声（可先 UVR 分离）  
2. WebUI → **训练** → 填实验名、采样率（常用 40k/48k v2）  
3. 一键训练或分步：预处理 → 提 F0/特征 → 训练 → 训练索引  
4. 小模型会出现在 `assets/weights`，约 60MB，**分享这个**，不要分享 `logs` 里几百 MB 的中间 ckpt  

详见 `docs/cn/faq.md` 与 `docs/en/training_tips_en.md`。

## 7. 本仓库相对「纯官方 7z」多了什么

| 项目 | 说明 |
|------|------|
| `一键启动.bat` + `launcher/` | 图形菜单，小白不用记一堆 bat |
| 安全加载 / 路径校验 | 见 `docs/RVC_ANALYSIS.md` |
| 下载脚本增强 | 跳过已有、重试、进度 |
| 文档 | 本说明 + 分析报告 |

**算法与 WebUI 布局保持官方 RVC**，避免做成和 B 站教程对不上的另一套产品。

---

## 8. 常见问题（视频评论区同款）

| 现象 | 处理 |
|------|------|
| Connection Error | 关代理；别关黑色控制台窗口 |
| 没有音色 | `.pth` 放 `assets/weights`，点刷新 |
| 分享模型别人用不了 | 分享 weights 下 60MB 小模型 + index，不是 logs 里大文件 |
| 显存不够 | 减小 batch；推理调小 config 里 pad 相关参数 |
| 装不上依赖 | 直接用 HF 完整 7z 的 `runtime` |

---

## 9. 打包「双击 exe」

若本机已装 Python + PyInstaller：

```bat
scripts\build_launcher_exe.bat
```

成功后根目录生成 `RVC启动器.exe`。  
**注意**：exe 只是启动器壳；完整推理仍依赖本目录代码、`runtime` 或系统环境与模型文件。真正「一个 exe 包含全部 CUDA」的只有官方数 GB 整合包。
