# 音频库阶段二实现状态

更新于 2026-09-23，分支 `tm-release`。本阶段延续[阶段一](音频库阶段一实现状态.md)，不代表音频与快捷键计划整体完成。
这是阶段二时点快照；后续进展见[阶段三状态](音频库阶段三实现状态.md)。

## 已实现

- 导入及刷新来源时显示已发现的音频文件数，可取消扫描。取消时不提交本次音频库变更；复制导入会清理本次已建立的副本。
- 可重新定位引用模式的文件或文件夹来源。失联来源重新定位后，原条目、片段和固定编号继续使用原身份；新位置中新增的文件也会加入音频库。
- 可重新定位来源文件夹内的单个失联文件。如果刷新已把目标文件另建为未编辑条目，会先征求确认，再以原条目身份接管它；已有编号、片段或编辑的目标条目不会自动合并。来源重叠且共用资产时，整目录重新定位会明确拒绝，避免误绑。
- 本阶段不触碰原文件，也不删除音频库之外的数据。

## 待继续

- 音频送入语音、与变声共用单一输出端、叠加播放、动态快捷键、悬浮窗播放控制、波形缓存等仍未实现。
- Windows 真实声卡和 CABLE 隔离及安装包验收待用户回到 Windows 后进行；本阶段不声称完成实机验证。
