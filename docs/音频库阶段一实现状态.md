# 音频库阶段一实现状态

更新于 2026-09-23，分支 `tm-release`。本文件记录已经接入产品的能力，不代表音频与快捷键计划整体完成。

## 已实现

- 导航和首页可进入音频库。导入文件或文件夹时可引用原文件或复制入库；文件夹可选择递归扫描。
- 音频库保留来源、资产和条目的稳定标识。重叠来源去重；固定编号允许稀疏正整数且不会随排序、刷新或其他条目变化而重排。
- 可命名条目和片段、设置播放范围、排除及恢复来源中的文件。刷新会保留失联文件的条目与编号。
- 可选择本地输出设备试听，试听支持暂停和停止。试听不使用 RVC 运行时，也不会主动选择系统默认输出设备。
- 可通过系统保存对话框准确另存 WAV；已有文件不被覆盖，导出可取消。
- 音频库数据位于 `User_Data/audio/`，不随仓库提交。安装包继续使用产品根目录的 FFmpeg 和 ffprobe。

## 尚未实现及验收

- 向语音软件输出音频、与 RVC/DSP 共用单一输出端、叠加播放和独立实例控制尚未接入。当前界面只提供本地试听，不能把“试听”当作语音内播放。
- 音频条目的动态快捷键、悬浮窗播放控制、波形与峰值缓存、批量管理、重新定位失联来源尚未接入。
- 尚未在 Windows 实际声卡及 CABLE 上测试试听隔离、驱动兼容与系统音频共存。真实安装包的 FFmpeg/ffprobe 负载也未在本机打包验证。
- 本机完整 Rust 测试有 397 项通过、28 项失败。失败项集中在既有 STS 来源、worker 和 i18n 测试，仍需在 Windows 环境复核。新增音频库与文件发布测试均通过。前端完整测试、类型、静态检查与八语言校验通过，Windows 目标编译检查通过。
