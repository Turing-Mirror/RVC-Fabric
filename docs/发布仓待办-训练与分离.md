## 0. 先看这里：清单加了 `extras` 段

分离模型和训练底模**不写死在客户端里**。以前 engine-core 和 VB-Cable 的
sha256 是硬编码在 exe 里的 —— 那是因为它们各只有一个版本。模型是会加的，
每加一个就发一版客户端谁都受不了。

所以现在从 `catalog-src/extras/*.yaml` 走，编译进 `index.json` 的 `extras`：

```yaml
# catalog-src/extras/pymss_vocals.yaml
key: pymss_vocals              # 必须和文件名一致
label: 人声分离模型（BS-RoFormer）
dest: assets/pymss             # 相对安装目录，禁止绝对路径和 ..
release_tag: pymss
channel: release
files:
  - name: bs_roformer_vocals_gabox.ckpt
    sha256: <传完之后 sha256sum 出来填这里>
    size_bytes: 639254584
  - name: bs_roformer_vocals_gabox.yaml
    sha256: <同上>
    size_bytes: 2279
```

`sha256` 和 `size_bytes` 必须写死，**没有就编译不过**。这两个字段在发布仓的
git 里没有对应文件可以现算 —— 权重只在 Release 附件里。少了它们客户端就没法
判断下载是不是完整，六百 MB 下错了没人看得出来。

`dest` 只允许安装目录下的相对路径。清单是客户端从网上拉的，放行绝对路径或
`..` 等于把任意写文件的权限交出去。编译器和客户端两边都会拦。

加完跑：

```bash
python scripts/build_catalog.py check --urls
```

## 1. 封面 `covers` —— 已完成

2026-08-01 已经传完，15 张，`cover_url` 也已经指过去了。列在这里只是记账。

| 项 | 值 |
|---|---|
| tag | `covers` |
| 内容 | `ch-banner/` 下的 15 张 jpg，文件名不变 |
| 地址 | `-/releases/download/covers/<文件名>.jpg` |

**为什么不能留在 git raw**：CNB 的 git-raw 响应不带 `Content-Type` 却带
`X-Content-Type-Options: nosniff`，浏览器既不知道是图片又不许自己嗅探，
`<img>` 直接不渲染 —— 这就是「社区音色不显示封面、模型页正常」的原因。
Release 附件按扩展名给 `image/jpeg`，没有 nosniff。

**以后加封面**：`ch-banner/` 里放一份（给人看、给校验），同时传一份到 `covers`
tag。两边文件名必须一致，`build_catalog` 是按文件名拼地址的。

## 4. Setup 要重打一次

不是发布仓的事，但别漏：`logs/mute` 现在会进安装包了（1.4 MB）。

训练拼 filelist 的时候末尾要补两条静音样本 —— 数据集小的时候 batch 里可能
全是有声帧，模型学不到「静音该输出什么」，推理时静音段会出噪声。以前
`logs/` 整个不进包，所以老的 Setup 装出来是训不了的。

已经装了老版本的内测用户，光靠 GUI 补丁**补不上**（补丁规则里 `logs/` 是
黑名单）。要么重装 Setup，要么手动把 `logs/mute` 拷进安装目录。

## 关于依赖：不用重打运行时

分离和训练需要的 Python 包 —— `av` / `librosa` / `soundfile` / `tqdm` /
`PyYAML` / `numpy` / `torch` / `tensorboardX` / `matplotlib` / `pyworld` /
`faiss-cpu` / `scikit-learn` —— **全都已经在我们 `requirements/requirements.txt`
里**，也就是说现有的三个 Runtime tar 都带着。所以这两个功能只需要下模型权重，
**不需要重新打包 4–6 GB 的运行时**。

唯一的风险点是版本：我们钉的是 `librosa==0.9.1` / `numpy==1.23.5`，都偏老。
PyMSS 在这个组合下跑不跑得起来，只能在 Windows 真机上试。跑不起来的话再谈
补一个「额外依赖包」走下载渠道，别急着重打整个运行时。

## 顺手记一笔：令牌权限

发布仓的 `cnb cli` 个人访问令牌只有 `repo-release:rw`，**没有 `repo-code:rw`**，
直接 `git push` 会 403（第一次还会报「版本庫未找到」，很误导）。现在推代码用的
是 `~/.cnb/token` 里的 OAuth 令牌。想让 AI 侧一条链路走到底，给那个 PAT 补上
`repo-code:rw`。
