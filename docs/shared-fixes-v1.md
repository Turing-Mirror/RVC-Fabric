# 通用功能修复 v1

日期：2026-11-07。

## 范围

保留现有导航、模型页布局和分类清理方式，统一修复封面裁剪、离场页面状态与存储统计。共享组件 `trm-ui` 更新到已核实的主分支提交 `f326946841baaff32d7f0372f3b013334a104dad`。

## 封面

- JPEG 导出先使用现有 `--group-ink` 浅色令牌填充背景，再绘制源图。裁剪后的预览和保存使用同一流程，透明 PNG 不再变成黑底。
- 当前封面读取和选图共用请求序号，旧图片晚到时不会覆盖新选择。退出时撤销拖动监听并使未完成的读取失效。
- 编辑区独立滚动，标题和操作按钮保持可见。画布高度有上限，窄窗口不会被竖图撑开。保存和选图期间保留按钮原文。封面和存储组件直接订阅语言上下文，异步读回语言或切换语言时同步刷新文案。
- 继续使用 RVC 原有封面读写命令、重置能力及输出尺寸规则。

## 页面状态

- 保留原有方向切页动画与页面实例复用，在离场层提供 `PageActive`、`inert` 和 `aria-hidden`。
- 模型菜单、作者弹窗和封面编辑在离开页面时关闭；返回时不恢复旧弹层。
- 模型目录与索引、预设面板分别隔离异步请求，旧模型响应不能覆盖新选择。相同模型的参数刷新保留面板内容，避免反复清空造成闪动。
- 初始 DSP 配置读取不能覆盖之后的选择；过期操作不会回滚较新的页面状态。
- 未修改现有 `useConfig` 并发控制。

## 存储

- 新增运行环境、公共模型、音频文件与其他用户文件。统计受管理的全部运行环境、旧版 Runtime、公共 assets、音频库、裁剪音频、语音合成和语音转换输出，并读取已保存的自定义训练及语音合成输出目录。
- 已发布音色、训练文件、下载缓存、临时文件、程序日志、诊断包、性能报告和回收站继续单独统计。现有分类清理命令和回收站行为保持不变。
- 使用规范路径全局去重；嵌套分类优先归属具体目录；联接别名和循环不会重复累计。分类根目录保留自身归属，穿过联接也不会被另一分类抢占。
- 自定义输出指向软件根目录或其上级时，只统计对应的直接输出文件，避免把整个应用或磁盘算作生成结果。
- 临时文件的可清理大小包含下载缓存，与后端实际清理范围一致。刷新失败单独显示，不覆盖已完成的清理结果。统计和训练扫描中一项失败时仍展示另一项成功结果。

外部分离输出目录未持久化，因此不会推测历史任意目录。统计按文件逻辑大小累计，不代表文件系统压缩后的实际分配空间。

## 下载状态

附加资源下载完成或失败时，正确展示共享下载状态中的结果提示；重试从零开始显示进度，不沿用上一轮进度。

- 全量前端测试：259 项通过。定向前端测试：29 项通过，覆盖页面活动状态、快速往返挂载、旧模型响应、清理成功后刷新失败、菜单交互、图片尺寸和现有配置并发回归。
- TypeScript、修改文件 ESLint、八语言键及占位符检查通过。
- 真实 Chromium：透明源角落为 `[0,0,0,0]`，保存角落为 `[255,255,255,255]`，预览与保存一致；迟到旧封面不覆盖新图；880×640、1180×780 及来回调整窗口时保存按钮可见；模型菜单切页关闭且返回不复活；存储新增分类无横向溢出，浏览器错误为零。
- 八种语言的 880×640 裁剪检查全部通过：保存按钮可见，无横向溢出。
- Rust 全量测试 496 项通过，1 项既有桌面窗口测试跳过。定向测试 4 项通过，覆盖嵌套目录、重复路径、Windows 联接循环、分类归属、运行环境及音频目录覆盖、应用根目录输出边界。
