## 项目结构与执行链

RVC Fabric 是 Windows 桌面变声与音频工具。React 19、TypeScript、Tailwind 4 和 Vite 7 提供界面；Tauri 2 与 Rust 管理窗口、设备、配置、下载、任务和原生音频；独立 Python 环境承载 RVC 推理及模型计算。

| 层 | 职责 |
| --- | --- |
| `app/src` | 七个主页面、底栏、独立工具窗、悬浮窗、语言与环境引导、状态和配置 |
| `app/src-tauri/src` | Tauri 命令、工作进程、音色/索引/档案、音频库、资源下载和更新、设备恢复、全局快捷键 |
| `app/audio-core` | FFmpeg 解码、重采样、CPAL 播放、有界音频缓冲、实时语音与音频混合 |
| `tools`、`gui_v1.py` | RVC/DSP 实时 worker、分块处理、STS、训练、分离、录音与模型工具 |
| `infer` | RVC 网络、特征提取、音高算法、推理与训练；包含上游实现 |
| `tools/pymss*` | 分离调度和各模型族实现 |
| `configs` | 参数范围、DSP 预设、资源清单与运行环境完整性描述 |
| `scripts` | 负载筛选、构建、清单编译、音色包验证和发布辅助工具 |
| `User_Data` | 音色、设置、音频条目、运行环境、日志与任务状态；不属于安装包内容 |

界面通过 Tauri 命令调用 Rust。实时控制使用 `runtime_control/command.json` 的序列号与确认机制，状态写入 `status.json`；PCM 音频走共享内存和有界队列，不走 JSON。RVC worker 加载 `gui_v1.py` 与推理模块，DSP worker 不加载 RVC/torch，但仍需要 Python 音频运行环境。原生音频库可以独立播放并与实时麦克风混音。

STS 优先复用匹配当前运行策略的已热 RVC worker，否则交给常驻转换 worker；文字合成先经 Windows SAPI，再按需转换音色。分离走 PyMSS。训练依次执行预处理、F0、特征提取、模型训练和 FAISS 索引，依据产物支持续跑。运行环境支持 NVIDIA、RTX 50 系和 AMD/Intel 多变体并存。

当前标准安装包为 Tauri NSIS 薄包。构建前筛选引擎负载，不捆绑运行环境、大模型、FFmpeg/ffprobe 或用户数据。模型和组件由产品按需补全。旧 Inno 脚本仍保留，不作为本次安装入口。

### B. 核心音频回归，约 10～15 分钟

1. 先确认旧音色、索引、参数档案、设备、音频条目仍在，现有运行环境无需重下。
2. 输入选真实麦克风，输出选 `CABLE Input`，监听选物理耳机；Windows 默认播放保持物理耳机。目标语音软件的麦克风选 `CABLE Output`。
3. 开启一个熟悉的 RVC 音色说话约 30 秒，切旁路原声，再切回；换另一个音色。通过标准：电平变化、监听和对端实际收到声音，显示音色与听感一致，没有上一音色残留。
4. 试花栗鼠、巨人、幽灵和变异 DSP；再回到 RVC。通过标准：预设可生效/关闭，不叠留上一个效果，原 RVC 音色可恢复。
5. 播放一段本地音频并同时说话。分别停止音乐、停止变声。通过标准：两支独立控制；本地试听与 CABLE 输出路由正确，无一支停下带停另一支。
6. 使用 5～15 秒样本做一次文件转换和一次文字合成；已有分离组件时再分离一段短音频。检查结果存在、时长合理、可试听；可正常取消。验证文案无需长时间训练或删掉环境重装。
7. 隐藏主窗口后使用自己已配置的全局快捷键。通过标准：仍可启停/播放，长按不连触发，关闭软件后不遗留本次工作进程占声卡。

### C. 长采样块专项，选测

在 44.1/48 kHz 的可用设备组合上，分别用 0.06、0.28、0.58、1.13、1.5 秒采样块说话约 30 秒。长块延迟增加是预期现象；不应被截成间断、无声、重复尾音或只有监听断声。结束后恢复自己的常用参数。这是整包回归项，长块修复来自更早的 1.7.1，不是这次新增。
