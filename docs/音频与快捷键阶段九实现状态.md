# 音频与快捷键阶段九实现状态

更新于 2026-09-24，分支 `tm-release`。本阶段接续[音频库阶段八](音频库阶段八实现状态.md)。

## 已实现

- 全局快捷键只在每次按下沿触发一次，松开与长按重复事件不会重复执行动作。
- 旧九项快捷键的动作、配置键和默认组合统一放在前后端共用的目录；配置默认值、Rust 注册器和设置页使用同一份数据，保留既有组合和全局范围。
- 目录已列出按条目播放、暂停当前、停止当前、停止全部和打开音频页等音频动作，不预设组合键。

## 待继续

- 动态绑定的保存、范围、冲突处理、差量注册、后台音频执行与设置界面尚未接入。目录中的音频动作目前只是定义，不能当作已经可用的快捷键。
- Windows 实机的全局键位兼容、输入法、长按与占用冲突行为留待设备验收。
