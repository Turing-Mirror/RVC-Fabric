# RVC Fabric 接入 TRM UI v1

RVC 的通用界面实现通过 `app/package.json` 中的 `trm-ui` Git 依赖引用。依赖固定到一个提交，锁文件随代码提交。组件源码由 TRM UI 维护，RVC 不保存其源码副本。

## 共用范围

- 基础布局、按钮、字段、数值条、复选框、分段控件、提示框与环形图。
- 自绘选择框、更多菜单、弹窗基础层、键盘焦点管理和条件渲染退场。
- 列表流动、文字切换、详情展开与内容切换动效。
- 设计变量、公共组件样式、输入方式识别、浮层定位和翻译查找/插值。

原有 `app/src/components/` 导入路径保留为转出或薄适配层。适配层仅设置 RVC 原有的间距、按钮外观、文案和动画节奏。`app/src/index.css` 导入 `trm-ui/styles.css`，只保留产品样式和已有外观差异。

## 产品边界

音频路由、变声引擎、模型管理、训练、引导、更新提示、错误处理和窗口业务继续在 RVC 中维护。标题栏、页面缓存/导航和业务面板继续使用现有产品组合。

RVC 持有语言状态，继续按需加载产品语言包、同步 Rust 语言和维护术语表。`I18nScope` 将当前语言提供给共享组件；语言切换不会重挂产品页面。自绘选择框和数值条的现有文案由适配层传入。

## 更新与验证

先在 TRM UI 修改、验证并提交共享实现，再在 `app/` 更新依赖：

```sh
npm install --save-exact "git+https://github.com/Turing-Mirror/TRM-UI.git#<commit>"
npm test
npm run build
```

提交 `package.json` 与 `package-lock.json`。安装不依赖本机相邻的 TRM-UI 目录；Git 依赖的 `prepare` 生成组件包。React 使用产品自己的实例。

构建会同时生成共享组件的 Tailwind 样式。回归验证应覆盖语言切换、菜单键盘操作、弹窗退场、提示与开关的事件边界、音频页列表和模型页状态。原有页面布局和业务流程保持，组件包升级随产品验证与发布。

## 设置页滚动修复

2026-11-07：`CatalogTransition` 用自然高度的 `QueueList` 承载分类内容，实际滚动归外层 `PageHost`。QueueList 默认的 `overscroll-behavior: contain` 将鼠标滚轮留在自身，即使其内容没有溢出，也阻断外层页面滚动。修复仅对产品的 `.catalog-transition` 设置 `overscroll-behavior: auto`，保留队列组件原有的独立滚动规则和左右切换动画。

复查时将指针放在设置卡片正文上，验证滚轮上下、连续小幅滚动、滚至末项、分类切换后滚动，以及离开设置再返回。覆盖默认和最小窗口尺寸，并在父组件持续刷新时确认滚动位置不复位。不要只检查 `scrollHeight` 或程序设置 `scrollTop`，这两者不能证明真实滚轮事件可以传给外层页面。
