# 在线更新与音色库 — 包规范与处理策略

> 实现代码：`launcher/online/`（`package_spec.py` 为类型与白名单权威定义）  
> 界面：主界面导航 **「更新」**  
> 本地版本：`launcher/version.py` → `APP_VERSION`

---

## 1. 总览：三种包，两种安装通道

| 包类型 | 英文 `package_type` | 内容 | 软件内操作 | 软件外操作 |
|--------|---------------------|------|------------|------------|
| **增量壳层包** | `gui_patch` | 仅 GUI/launcher/配置等小文件 zip | **下载 → 校验 → 白名单合并覆盖** → 提示重启 | 也可手动解压覆盖对应文件 |
| **全量发行包** | `full_package` | 含 `Runtime/`、exe、完整资源 | **禁止合并安装**；只打开 SharePoint/浏览器下载 | 下载后**解压到新目录**使用，或按说明整包替换 |
| **音色包** | `voice_pack` 或 `voice_files` | 模型权重与可选 index/封面 | **下载 → 安装到 `User_Data/models/<id>/`** | 可手动复制到 models 目录 |

原则（与原版 RVC「网上下资源」、B 站整合包习惯对齐）：

- 日常热更只动**壳层增量**与**音色**。  
- **Runtime / 显卡分版完整包**体积大、环境敏感，**永不**在 RVC Fabric 进程内静默覆盖当前安装。  
- 直链渠道：**CNB**（主索引 `index.json` + LFS / Release）、GitHub raw；社群分发：**QQ 群**。  
- **CNB 主索引**：`https://cnb.cool/Turing-Mirror/RVC-Fabric-Releases/-/git/raw/main/index.json`  
  音色字段：`name` / `author` / `author_url` / `date|released`(YYMMDD) / `cover_url`（`ch-banner/`）。  
  详见 `docs/CNB-index索引与封面.md`。

## 2. 增量包（`gui_patch`）

### 2.1 何时发增量包

- 只改了 `launcher/`、界面、少量 `tools/`、`configs/online_catalog.json`、`gui_v1.py` 等  
- **不**需要换 Python/CUDA Runtime  
- 用户希望「点一下更新」即可  

### 2.2 包格式要求

1. 必须是 **`.zip`**（UTF-8 路径更佳）。  
2. 内部路径 = **相对软件根目录**（解压后与主界面 exe 同级结构），例如：

```text
tm_package.json          ← 强烈推荐
launcher/main_app.py
launcher/theme.py
launcher/online/...
configs/online_catalog.json
tools/realtime_worker.py
gui_v1.py                ← 可选，根目录白名单文件
```

3. 根目录（或包内）**推荐**包含 `tm_package.json`：

```json
{
  "schema": 1,
  "package_type": "gui_patch",
  "format_version": 1,
  "name": "TM Voice GUI",
  "version": "1.2.0",
  "min_app_version": "1.0.0",
  "notes": "修复某某；请重启 RVC Fabric",
  "applies": "merge_allowlist"
}
```

| 字段 | 含义 |
|------|------|
| `package_type` | 必须为 `gui_patch`（别名：`incremental` / `patch` / `delta`） |
| `version` | 增量包版本；应 ≥ 清单里 `app.gui.version` |
| `min_app_version` | 可选；当前 `APP_VERSION` 低于此值则**拒绝安装**（要求用户先全量或中间版） |
| `notes` | 更新说明 |

4. **允许写入**的路径前缀（白名单）：

- `launcher/`  
- `configs/`  
- `docs/`  
- `i18n/`  
- `scripts/`  
- `tools/`  
- `tests/`  
- 根目录个别文件：`gui_v1.py`、`infer-web.py`、`package_meta.json`、`version.txt`、`README.md` 等（见 `package_spec.GUI_ALLOWED_ROOT_FILES`）

5. **禁止写入**（命中则跳过；若 zip 整体像全量包则整包拒绝）：

- `Runtime/`、`User_Data/`  
- `assets/hubert|rmvpe|pretrained|pretrained_v2|uvr5_weights|weights/`  
- `VBCABLE/`、`RVCMAX/`、`dist/`、`build/`、`.git/`  

6. 可选：整包外再套一层文件夹（如 `TM_GUI_1.2.0/launcher/...`），安装器会尝试剥掉**非白名单名**的单层包装目录。

### 2.3 软件内处理流程

```text
检查清单 → 比较 APP_VERSION 与 gui.version
  → 用户确认
  → 下载 zip 到 User_Data/update_cache/gui/
  → 读取 tm_package.json + 内容嗅探
  → 若判定 full_package → 中止并提示外链安装
  → 若 min_app_version 不满足 → 中止
  → 按白名单解压合并到软件根目录
  → 写入 update_state.json 记录
  → 提示重启
```

### 2.4 运营如何制作增量包

```bat
python scripts\pack_gui_patch.py --version 1.2.0 --out dist\gui_patch_1.2.0.zip
```

上传 zip 到 CNB（LFS）后，把打印出的 `sha256=` 写进
`CNB-GIT-RELEASE\catalog-src\app.yaml`（**不再手改任何 json**）：

```yaml
version: 1.2.0
channel: stable
gui:
  package_type: gui_patch
  version: 1.2.0
  sha256: <pack_gui_patch 打印的 sha256>   # url 由 sha256 自动推导为 LFS 直链
  min_app_version: 1.0.0
  notes: 本次更新说明
```

然后 `python scripts\build_catalog.py build --diff` 生成三份清单产物并核对。
同时把仓库内 `launcher/version.py` 的 `APP_VERSION` 升到新版本（下次打包进增量包）。

## 3. 全量包（`full_package`）

### 3.1 何时发全量包

- 更换 / 升级 **Runtime**（CUDA / DirectML / 50 系）  
- 首次安装、大版本重构、增量跨度过大  
- 需要整包主界面 exe + `Runtime` + 资源  

### 3.2 包内容要求

典型发行目录（由 `scripts/build_release.py` 产出；目录名见分版文档）：

```text
TuringMirror_Voice_Nvidia/   （打包脚本目录名；产品 RVC Fabric）
  变声器.exe / 启动器.exe
  Runtime/                 ← 必需
  launcher/ 或已打进 exe
  assets/  configs/  User_Data/  VBCABLE/  …
  package_meta.json
```

压缩上传时可为 `.7z` / `.zip`，**体积通常数 GB**。

### 3.3 软件内策略（强制）

| 步骤 | 行为 |
|------|------|
| 清单标记 `package_type: full_package` | 「下载并应用增量包」按钮**禁用** |
| 用户点「全量包说明 / 打开链接」 | 打开 `community.sharepoint_full` 或配置的 URL |
| 若误把全量 zip 填进 `gui.url` 且用户触发应用 | 下载后**内容嗅探**到 `Runtime/` 等 → **拒绝合并**，文件留在缓存并提示手动安装 |

**不会做：** 静默解压覆盖当前目录的 `Runtime/`、删除用户 `User_Data`。

### 3.4 软件外用户操作

1. 从 **SharePoint** 或 **QQ 群** 下载全量压缩包  
2. 解压到**新文件夹**（建议英文路径）  
3. 运行新目录中的 **启动器.exe** / 主界面 exe  
4. 音色在 `User_Data/models`，可自行从旧目录复制  

### 3.5 清单写法

```json
"app": {
  "version": "2.0.0",
  "gui": {
    "package_type": "full_package",
    "version": "2.0.0",
    "url": "",
    "notes": "请下载全量包，勿使用增量合并"
  }
},
"community": {
  "sharepoint_full": "https://….sharepoint.com/…&download=1",
  "qq_group": "123456",
  "qq_link": "https://qm.qq.com/…",
  "note": "完整包（N/A/50 分版）仅 SharePoint 或 QQ 群"
}
```

全量包**优先**用 `community.sharepoint_full`，不要依赖软件内 apply。

## 4. 音色包

音色有两种交付方式，catalog 用 `package_type` 区分（可省略，由是否存在 `pack_url` 推断）。

### 4.1 方式 A：`voice_pack`（推荐 zip）

**一个 zip 装一个音色**，安装到 `User_Data/models/<id>/`。

#### 必需要素

| 内容 | 规则 |
|------|------|
| `*.pth` | **至少一个**；主推理模型，建议 > 50KB |
| 稳定 `id` | catalog 的 `id` 会作为目录名（安全化后） |

#### 可选要素

| 内容 | 规则 |
|------|------|
| `*.index` | FAISS 特征检索；无则软件仍可推理（index_rate=0） |
| `cover.png` / `cover.jpg` / `cover.webp` | 封面；首页/模型页展示 |
| `config.json` | 展示名、tag、默认 pitch、`series` 系列包名等 |
| `tm_package.json` | 声明 `package_type: voice_pack`、`voice_id`、`version`、`series` |

#### 系列包归类（`series` 字段）

`series` 是可选字符串，用于把同一IP / 同一来源的多个音色在「社区音色」窗口的**系列专区**里归组（如 `Mygo`、`VOCALOID`、`RVC原版`）。

- **社区音色**窗口四视图：**最新**（图灵镜源 + 第三方合流，按 `date` 从晚到早）；**图灵镜源**（官方 `voices[]`）；**第三方**（`thirdparty_voices[]`，顶栏免责声明）；**系列专区**（仅官方系列折叠，第三方不参与分组）
- 留空 = 单品音色，只出现在最新/图灵镜源平铺，不进系列专区
- catalog 与音色 zip 内 `config.json` / `tm_package.json` 任一处写入均可；客户端识别字段名 `series` / `series_name` / `collection`
- 搜索框会同时匹配 `series` 字段（占位文案已标注「系列」）
- **下载并发**：最多 2 个音色同时下载，其余进等待队列（`launcher/online/download_queue.py`）；下载按钮即状态显示——`下载安装` / `待下载` / `NN%` / `重新下载`，重复点击自动忽略，关窗后下载继续
- **中文标题**：有中文角色名的条目 `name` 直接写中文（如 `千早爱音`），`id` 保持拉丁名（`Anon`）；界面标题旁会附拉丁 id 小字；zip 内 config 只有拉丁名时，安装后以清单中文名为展示名

#### 第三方源（`thirdparty_voices`）

| 项 | 说明 |
|----|------|
| 清单键 | `index.json` 顶层 `thirdparty_voices[]`（老客户端忽略未知键） |
| 源 YAML | `CNB-GIT-RELEASE/catalog-src/thirdparty/<id>.yaml`，**id 强制 `tp-` 前缀** |
| 制品 | 直链指向公开社区站（常见 Hugging Face）；**不**镜像到 CNB LFS |
| 国内下载 | 客户端把 `huggingface.co` 重写为 `hf-mirror.com`（`app_config.json` → `hf_endpoint`；`official`=直连） |
| 安装章 | `publisher=community`、`fabric_official=false`、`source=thirdparty_*`；zip 内伪装官方章会被压掉 |
| 收编工具 | `python scripts/add_thirdparty_voice.py --hf org/repo --yes` → `build_catalog.py build` |
| 免责 | 第三方页固定声明：授权/音质/版权/使用后果与 RVC Fabric 官方无关 |

详细方案：`docs/第三方音色下载方案.md`。

```json
{
  "id": "tomori",
  "name": "高松灯",
  "series": "Mygo",
  "pack_url": "https://…/tomori.zip"
}
```

#### 推荐 zip 结构

```text
tm_package.json
config.json
MyVoice.pth
MyVoice.index
cover.png
```

或单层目录：

```text
kiki/
  tm_package.json
  config.json
  kiki.pth
  kiki.index
  cover.png
```

### 4.1.1 本地导入与磁盘放置规范（软件内「导入音色」）

安装完成后的**固定位置**（在线包与本地导入相同）：

```text
User_Data/
  ch-banner/                 # 本地角色封面（与 CNB ch-banner 对应）
    <id>.jpg
  models/<名称>/
    *.pth            # 模型权重（必需）
    *.index          # 特征检索库（可选，必须与 .pth 同一文件夹）
    cover.jpg|png    # 封面副本（可选，安装时也会写）
    config.json      # 参数、index 绑定、active_profile（软件维护）
    profiles/*.tmvp  # 配置档案（可选）
```

`config.json` 的 `cover` 推荐写 **`ch-banner/<id>.jpg`**（相对 `User_Data/`）。  
软件读封面时顺序：绝对路径 → `User_Data/ch-banner/` → 安装根 `ch-banner/` → 音色文件夹内 `cover.*`。

| 用户选择 | 软件行为 |
|----------|----------|
| 仅 `.pth` | 建 `models/<名>/`，复制/移动 .pth；若源目录有同名/同干名 `.index` 会自动一起拷入并绑定 |
| `.pth` + `.index`（可多选） | 按文件名匹配成对，**都放进同一音色文件夹**并绑定 |
| 仅 `.index` | **复制进当前选中音色**的文件夹并设为使用中（需先点选一个音色） |
| `.zip` | 与 CNB/社区 `voice_pack` 相同：`install_voice_pack_zip` 解压安装 |

**不要**把 `.index` 单独扔在软件根目录、`assets/` 或其它全局目录当默认位置——检索库以「跟音色文件夹走」为规范，换机/备份只需拷贝整个 `models/<名称>/`。

`config.json` 示例（RVC Fabric 发布包必填身份字段）：

```json
{
  "name": "浅夏",
  "author": "作者名",
  "author_url": "https://example.com/author",
  "date": "260722",
  "cover": "ch-banner/kiki.jpg",
  "tag": "少女音",
  "series": "RVC原版",
  "version": "1",
  "pitch": 12,
  "publisher": "rvc_fabric",
  "fabric_official": true,
  "online_id": "kiki"
}
```

| 字段 | 含义 |
|------|------|
| `name` | 音色名称 |
| `author` | 作者 |
| `author_url` | 作者链接 |
| `date` | YYMMDD |
| `cover` | 封面路径：包内 `cover.jpg` 或本地 `ch-banner/<id>.jpg` |
| `series` | 可选；系列包名（如 `Mygo` / `VOCALOID` / `RVC原版`），社区下载按此分组 |

安装后写入 `User_Data/models/<id>/config.json`；模型页卡片显示作者。

`tm_package.json` 示例：

```json
{
  "schema": 1,
  "package_type": "voice_pack",
  "voice_id": "kiki",
  "name": "浅夏",
  "version": "1",
  "tag": "少女音",
  "publisher": "rvc_fabric",
  "fabric_official": true,
  "applies": "install_to_user_data_models"
}
```

### 4.1.1 如何识别「RVC Fabric 官方音色」

客户端（咨询包 / 默认不上传大模型）按**任一命中**判定为官方库音色：

| 信号 | 来源 |
|------|------|
| `publisher: rvc_fabric` 或 `fabric_official: true` | 包内 `config.json` / `tm_package.json`（离线可靠） |
| `source: online_pack` / `online_files` | 从软件「更新」页安装时写入 |
| `online_id` 非空 | 安装目录身份；咨询包 `model_meta` 必带 |
| `online_id` ∈ 本地/远程 catalog 的 `voices[].id` | 与 CNB/清单对照（bundled + 缓存） |

官方运营：用 `scripts/pack_voice_pack.py` 打的包会自动写入 `publisher` / `fabric_official` / `online_id`；清单仍由仓库汇总的 `online_catalog.json`（或远端 manifest）提供 id 列表。

#### 软件内处理

```text
下载 pack_url → 缓存
  → 拒绝 full_package / 无 pth
  → 清空 models/<id>/ 后写入 pth/index/cover/config
  → 刷新模型列表
```

制作：

```bat
python scripts\pack_voice_pack.py --id kiki --name 浅夏 --pth path\to\model.pth --index path\to\a.index --cover cover.png --series "RVC原版" --out dist\kiki_voice.zip
```

`--series` 可选；留空则该音色在社区下载中归入未分组区。

Catalog：

```json
{
  "id": "kiki",
  "name": "浅夏",
  "tag": "少女音",
  "package_type": "voice_pack",
  "pack_url": "https://…/kiki_voice.zip",
  "sha256": "可选",
  "size_bytes": 60000000
}
```

### 4.2 方式 B：`voice_files`（多直链）

不打 zip，清单分别给文件 URL：

| 字段 | 必需 | 说明 |
|------|------|------|
| `pth_url` | 是 | `.pth` 直链 |
| `index_url` | 否 | `.index` |
| `cover_url` | 否 | 图片 |
| `sha256` | 可选（音色） | 校验 pth 或 zip；**GUI 增量应用时 catalog 侧必填** |

处理：分别下载 → 写入 `User_Data/models/<id>/` → 生成 `config.json`。

## 6. 直链与校验

### GitHub

- Release：`…/releases/download/<tag>/file.zip`  
- Raw：`raw.githubusercontent.com/...`  
- `github.com/.../blob/...` 会自动转 raw  

### 腾讯 CNB（RVC-Fabric-Releases 制品仓）

| 用途 | URL 形态 | 说明 |
|------|----------|------|
| 清单 / 小文件 | `…/-/git/raw/<branch>/<path>` | 匿名可用；例：`catalog/online_catalog.snippet.json` |
| **LFS 大文件（音色 zip / Runtime）** | `…/-/lfs/<sha256>` | **内容哈希**（与文件 sha256 / LFS oid 相同）；**GET 下实体**；HEAD 可能 404，软件用 GET |
| 浏览器页面 | `…/-/blob/<commit或branch>/<path>` | HTML，不可直接当下载体 |

示例（音色）：

```text
https://cnb.cool/Turing-Mirror/RVC-Fabric-Releases/-/lfs/dfb9a54afe78a95b32f1742090bd55541c28a205f3f958884247e4a454e2aeb3
```

- `pack_url` / `sha256` 由 `scripts/build_catalog.py` 从本地制品**自动生成**（LFS oid = 文件 sha256），无需手填  
- 若误填 `git/raw`：raw 只返回 LFS 指针；下载器会解析 oid 并自动改走 `/-/lfs/<oid>`  
- 产品默认 `manifest_urls` → CNB 上 `index.json`（主）与 `catalog/online_catalog.snippet.json`（兼容），两者均为 build_catalog 生成物  
- 本地制品：`CNB-GIT-RELEASE/`（gitignore）；`pack_cnb_release.py` 只负责打制品/边车，**不再写 snippet**（`--write-manifest` 已废弃）

### SharePoint / OneDrive

- 必须是**匿名可访问**分享  
- 建议 `download=1`  
- 需登录的链接无法在软件内静默下载  

### sha256（重要）

| 场景 | 策略 |
|------|------|
| **GUI 增量包应用** | **必填** `app.gui.sha256`。未填写时软件**拒绝**一键应用（供应链安全，对齐常见桌面更新器校验思路） |
| 音色 pack / pth | 可选；填写则校验，失败中止 |
| 制作增量包 | `python scripts/pack_gui_patch.py ...` 结束后会打印 `sha256=`，写进 `catalog-src/app.yaml` 后 `build_catalog.py build` |

校验失败 → 删除临时 `.part` 并报错。  

### 安全解压

音色 zip **禁止** `extractall` 盲解。实现为 `launcher/online/safe_zip.py`：拒绝 `../`、绝对路径、跳出目标目录的成员（防 zip-slip）。  

### 音色列表

「更新」页展示条件：`pack_url` **或** `pth_url` 任一非空（`VoiceEntry.has_download()`）。仅 zip 包、无 pth 直链的条目也会显示。

## 7. 判定优先级（下载到 zip 之后）

1. zip 内 `tm_package.json` 的 `package_type`  
2. 否则内容嗅探：`Runtime/` / `python.exe` → **full_package**；仅有 pth 无 launcher → **voice_pack**；否则按 **gui_patch** 尝试  
3. catalog 声明与嗅探冲突时：**安全优先**（全量特征则拒绝当增量应用）

## 10. 常见错误

| 现象 | 原因 | 处理 |
|------|------|------|
| 应用增量失败「没有可应用的文件」 | 路径不在白名单或打成了全量 | 检查 zip 结构 |
| 提示是全量包 | 含 Runtime 或 package_type 写错 | 改走外链全量流程 |
| 音色安装失败无 pth | zip 空或只有 index | 补 pth |
| 下载到 HTML | SharePoint 需登录 | 改为公开链接 + download=1 |
| min_app_version 拒绝 | 跨度过大 | 先装中间增量或全量 |
